Reviewed web sources on microbial/extracellular metabolomics analysis. Main
takeaway: exometabolomics/metabolic footprinting commonly interprets spent
medium changes as microbial consumption/depletion and secretion/production
relative to a control medium, supporting fold-change versus blank medium as a
conceptually aligned input for the neural-response contrast. However, literature
does not give a single canonical post-fold-change distance. Common downstream
layers include log transforms, missing/QC handling, scaling choices, PCA/HCA,
differential abundance/fold-change effect size summaries, and pathway/network
interpretation. For this project, the searched sources support treating naive
full-space Euclidean distance as only one baseline rather than a privileged
biological geometry.

Synthesized literature around pathway/metabolite embedding when only measured
metabolites and bacterial category labels are available. Key framing: without
genome data, the analysis can estimate observed metabolic footprints, not
encoded pathway capacity. Public pathway/reaction databases, chemical ontology,
and empirical co-change can be used to build pathway/module-level embeddings
that summarize signed production and depletion before comparing samples.
Updated MEM-20260527-001 with this constraint.
