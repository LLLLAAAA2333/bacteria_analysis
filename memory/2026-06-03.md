## 00:22 | Diagnosed ASG amplification under active scaling

- kind: debugging
- tags: [86bac, neural-rdm, active-scaling, asg, sensitivity]
- topic: neural-representation
- source: user visual inspection + local analysis
- promotion_hint: candidate
- related_state: [state/heartbeat-state.json]
- related_memory: [MEM-20260529-001, MEM-20260603-001]

The scaled trajectory audit showed unusually large ASG values. ASG has no
date-stimulus prototype frames above the active threshold `0.2`, so
`compute_active_scales()` falls back to `mean(abs(all finite frames))`.
For ASG this fallback scale is only `0.022181`, much smaller than every other
neuron scale. Dividing by this small value amplifies ASG raw prototype values
from approximately `[-0.112, 0.130]` to scaled values approximately
`[-5.040, 5.868]`.

This materially changes the neural geometry rather than only the heatmap:
removing ASG yields full-versus-no-ASG neural RDM Spearman `0.785193`, median
absolute pair-distance delta `0.134027`, and neural-chemical RSA
`0.146140` versus `0.156744` with ASG. Treat the current all-neuron active-scaled
RDM as needing an ASG scaling sensitivity decision before it becomes the
default reference.

## 21:27 | Clarified neural correlation distance and MDS Shepard interpretation

- kind: interpretation
- tags: [86bac, neural-rdm, correlation-distance, cosine-distance, neural-mds, shepard-diagram]
- topic: neural-representation
- source: user request + code inspection
- promotion_hint: candidate
- related_state: [state/heartbeat-state.json]
- related_memory: [MEM-20260529-001, MEM-20260603-003]

Clarified that `neural_correlation_distance_matrix.csv` is Pearson correlation
distance (`1 - r` from `np.corrcoef`), not raw cosine distance. Pearson
correlation distance is equivalent to cosine distance only after each flattened
trajectory vector has been mean-centered, so the current neural RDM primarily
captures trajectory shape/pattern rather than absolute amplitude.

Also clarified that the current neural 3D MDS is classical metric MDS using the
precomputed neural correlation-distance RDM as input. Shepard diagrams should
plot original RDM pair distances on the x-axis and Euclidean distances between
the 3D MDS coordinates on the y-axis. MDS coordinates should not be normalized
for stress or Shepard diagnostics, because that changes the fitted distance
scale.
