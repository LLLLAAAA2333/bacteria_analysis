Reviewed the current neural-response representation question. The user
highlighted an AWC failure mode for peak summaries: similar biphasic traces can
receive opposite signed peaks when the larger lobe switches between
stimulus-period suppression and post-stimulus activation. The current
active-scaled flattened-trace correlation RDM remains a reasonable first
shape-focused view, but it should be validated explicitly and kept separate
from a response-strength representation. At the present stage, each stimulus is
better described as a trajectory, or a noisy bundle of repeated trajectories,
in a 13-dimensional neural state space rather than as an established manifold.
