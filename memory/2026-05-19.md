## 17:00 | Interpreted raw missing -> non1 fold-change values

- kind: analysis
- tags: [matrix-input, metabolism-analysis, fold-change, missingness, blank-normalization]
- topic: chemical-survey
- source: assistant
- promotion_hint: candidate
- related_state: [state/heartbeat-state.json]

Further inspected what `missing -> non1` means in `matrix.xlsx`. The raw `A`
samples absent from `matrix.xlsx` are likely medium blank/reference blocks:
`A050-A058`, `A088-A092`, `A225`, `A250`, `A306`, and `A316-A318`. When using
these block-specific blanks, raw missing cells that became matrix non-1 values
are consistent with a low/non-detect imputed absolute numerator divided by the
corresponding block blank mean:
`matrix_non1 ~= imputed_low_value / mean_medium_blank_for_block`.

Among 8,417 missing->non1 cells, 7,404 had finite block blank estimates. The
back-calculated imputed numerator had median `0.998`, IQR `0.727-1.146`, and
90th percentile `1.98`, with many values near 1. Thus most non1 values likely
come from replacing missing raw intensity by a small positive value around 1
before fold-change calculation. The non1 matrix values are not a single global
constant; they vary by chemical and sample block because blank denominators and
possibly low-value fill constants vary. This remains an inference from the
workbook values because the original matrix-generation script is not present.
