## MEM-20260518-002 Global chemical PCA review

Generated an exploratory PCA of the full QC20 chemical composition matrix at
`results/202604_without_20260331/global_chemical_pca_review`.

The reusable local script is
`data/local_taxonomy_category_performance_review/run_global_chemical_pca_review.py`.
It uses the current 52 sample set, filters raw-workbook chemicals with
`QCRSD <= 0.2`, transforms values with `log1p(raw concentration)`, median
imputes missing values, z-scores each chemical, and runs PCA on the full
sample-by-chemical matrix. PC signs are oriented so the largest absolute loading
on each PC is positive. Outputs include explained variance, sample scores,
all chemical loadings/contributions, top contributors, and figures for variance
and top loadings.

Updated the same script to also write one all-chemical loading plot per PC under
`figures/all_loadings/`, with chemicals sorted from most positive loading at the
top to most negative loading at the bottom.

The reusable script is
`.worktrees/chemical_survey/exploratory/chemical_survey/plot_qcrsd_missingness_relationship.py`.
