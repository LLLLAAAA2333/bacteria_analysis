# 跨动物神经响应结构：共享时程、细胞组合与额外时程

本分析限定于当前刺激协议下测得的钙响应表型。采集块采用记录中的 `date`；原始表没有独立培养批次或同日采集块字段。下面的跨动物结果针对已有菌株×日期条件，不支持新菌株或新培养批次的推广。

## 判断

允许各细胞分别改变响应方向和幅度，比只允许整个群体统一增益，增加了较多的跨动物预测能力。进一步放开时程，整体平均增加较小，但细胞之间差别明显，部分菌株条件有可重复的时程偏离。

AWCON 的主体响应可以用单模板作有用近似。AWB、AWCOFF、AWA、ASH 的额外时程证据分布较广；ADF、ASK、ASJ 有明确的局部反例，同时主体模板仍保留很多可重复差异。ASEL 的局部反例明确，但整类细胞的预测表现仍不足以作稳定概括。ADL、ASI、ASER、ASG 目前不能作总体判断。

这些是逐动物预测、模板及实际曲线共同支持的描述性判断，不是显著性检验，也不意味着同一类别中的所有菌株表现一致。

## 预测能力增加多少

损失为原响应单位的均方误差，单位 `(ΔF/F₀)²`；数值越低越好。增益保留负值。总体权重为细胞等权、细胞内菌株等权、同菌株各块等权、每条件时间窗等权、每窗有效动物等权。

| 窗口 | B | M0 | M1 | M2 | Δ组合=M0−M1 | Δ时程=M1−M2 |
|---|---:|---:|---:|---:|---:|---:|
| 0–40秒，主分析 | 0.075284 | 0.059065 | 0.036289 | 0.035484 | **0.022776** | **0.000805** |
| 0–25秒，预定检查 | 0.111446 | 0.084934 | 0.049540 | 0.048744 | **0.035394** | **0.000797** |

两窗口分别拟合并分别报告，没有按结果更换主窗口。缩短窗口后组合收益仍保留，额外时程也并非全部由25秒后的低信号造成。ASJ的窗口判断有所不同：0–25秒主体单模板仍有用，未显示明确的总体额外收益；其A014反例主要依赖晚期，不能把全窗的局部时程结论照搬到早期。短窗A247仍有较弱局部偏离候选，单模板近似不等于严格固定。

## 模板稳定性与最强三株反证

模板RMS固定为1，绝对值最大窗取正；系数允许负值，表示整条模板翻转。稳定性比较允许整体翻转，不对曲线做额外中心化。只统计确实移除了对应细胞训练数据的留出折，避免未观测该细胞的动物产生重复模板。

主窗口中，各细胞有效留出模板与全数据模板的最小绝对余弦均不低于约0.9948。由于训练集高度重叠，这只说明删去一只动物时模板不易改变，不能独立证明单模板充分；AWB和AWCOFF正是模板稳定、仍有额外时程的例子。

反证在每折训练集中按每细胞的条件均值RMS排序，同菌株跨块等权，固定排除最强三株的全部块来估计模板，然后使用全部原训练动物重估系数。测试集保持不变，排除名单逐折保存于 `tables/top3_exclusions.csv`。

总体M1 MSE由0.036289变为0.036318，增加约0.000030。各细胞相对B的收益方向均未改变；有效折的模板绝对余弦最低约0.9601，出现在ASEL。这个检查没有支持“模板完全由最强三株决定”，也没有将原本证据不足的细胞变为可判断。

## 数据与方法核对

- 原始输入：`data/106bac.parquet`。106菌株，112菌株×日期条件，49只动物，607个动物×条件记录。
- 与02 Notebook最终A–D的 `final_load_responses` 对照：607×104矩阵数值及NaN掩码精确一致。复用trial内L/R、动物内逐采样时刻trial均值、五个采样时刻分窗的顺序。
- 保留原ΔF/F₀及其上游基线定义，不重新拟合F₀，不对单条响应减均值或单位长度归一化。前九类合并L/R，ASEL、ASER、AWCON、AWCOFF分别保留。
- 全部刺激名称后缀均为 ` stationary`，没有同日同菌株不同名称冲突；`date`仍只是现有记录中的块代理，不能排除未记录的同日批次差异。
- 0–40秒共有56,504个有效动物×条件×细胞×窗值，55,880个进入比较。39个条件×细胞仅两只动物，其624个窗观测保留展示但不评分。这些格子位于ASEL、ASI、AWCON，三者各99个可评分条件，其余细胞各112个。
- 本数据缺失来自整细胞缺测，没有部分采样缺失窗。代码仍显式处理部分缺窗并记录每窗有效采样点数，缺失不填零。
- 全局49次整动物留一：同一动物的所有菌株、细胞和时间记录同时留出。四模型使用同一逐窗支持线：至少两只训练动物，测试值有效。所有模板、系数和基准曲线仅来自训练动物。
- B使用统一加权训练目标；M0约束增益非负；M1为未经中心化秩1；M2为逐窗训练动物均值。完整M1使用精确加权SVD，M0使用多初值约束交替最小二乘。所有实际拟合均收敛且支持可识别。
- 未采用细胞缩放。细胞等权并不意味着将不同响应幅度标准化；原单位平方误差仍会受到强幅度细胞的影响，因此保留逐细胞结果。
- 不计算以trial、时间窗或交叉验证折为独立重复的置信区间。均值、动物配对分布及定位结果是当前观察条件下的描述性证据。

推广对象的区分参考 [Schütt等，2023](https://elifesciences.org/articles/82566)。本分析没有计算新的RDM、嵌入、菌属分类或化学归因，也没有扩展多模板或离散类型模型。
