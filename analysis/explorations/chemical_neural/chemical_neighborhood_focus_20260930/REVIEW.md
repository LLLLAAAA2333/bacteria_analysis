# 化学近邻中的响应表型：收束后的检阅

**本轮只保留一个中心问题：化学谱相对接近的菌株，实际引起什么不同的群体钙响应？神经atlas在这里提供直接测量的生理表型。** 不再以群体轴或分类成绩组织主图，也不主张神经取代化学。

先看[主图：A022/A023的化学谱与配对响应](figures/chemical_neighbor_A022_A023.png)。左边是同一对菌株的380项log₂FC，右边是全部13类神经元中每只动物的实测响应差。无需理解降维坐标或分类器。

**最值得保留的例子是A022/A023。** 两株均标注B. stercoris，在原神经比较组及扩大的化学库同属同reference集合中，均互为化学最近邻。共同报告有值的332项中，93.7%的FC相差不超过两倍；这只是描述，不是混合物等价标准。当前协议下，同一动物的A022−A023平均钙响应差在ASK为+0.107（6/6动物为正）、ASH为+0.136（6/6）、AWB为+0.100（5/5），AWCON为−0.111（5/5）。单位均为ΔF/F₀，0–25秒；其余细胞也完整展示。由此能直接看见化学近邻内部的响应表型区别。

**保留范围与反例。** 45个化学近邻对、72株、49动物中，41对在多数动物的完整群体差向量上同向；删除单株或强例后仍保留总体趋势。但化学距离更小的[A007/A010](figures/chemical_neighbor_A007_A010.png)只有2/7动物的差向量与其余动物同向。化学邻近既不保证相同响应，也不保证一定存在稳定响应差异。

最强限制有两项：完整FC距离大小显著受原报告缺失后的填零影响；A022/A023的刺激顺序固定。前者已在化学散点中单独标记，并检查共同报告条目与扩大比较库；后者无法靠既有数据完全解除。因此保留“当前协议下的补充响应表型”，不升级为纯菌株因果效应、化学相同或已证明条件独立的信息增益。

研究叙事建议固定为：**化学表征提供组成参考，神经群体测量进一步描述这些混合物在动物中诱发的响应。** 最值得下一步检验的是，在可分离刺激顺序的记录中，固定本轮比较是否仍保留。
