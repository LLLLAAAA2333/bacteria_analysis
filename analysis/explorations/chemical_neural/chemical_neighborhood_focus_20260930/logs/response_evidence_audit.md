# 化学近邻内部群体差异：有界证据审计

本次只把已有结果改写为与科学问题一致、可直接核查的响应对比，并做有限的反证检查。没有重新筛选神经元、训练新模型或寻找新阳性结果。执行脚本：code/response_evidence_audit.py；状态：实际运行成功。

## 在问什么

对于仅由化学信息选出的菌株 A、B，同一动物中测得的 A−B 群体差向量，是否与其他动物的平均 A−B 差向量方向一致？这里的“同向”仅指两向量点积大于 0（夹角小于 90°），不表示响应曲线完全相同。

全部 13 类神经元从一开始均为候选坐标，每类采用 0–25 秒内 5 个 5 秒钙响应均值。每次留出一只动物，按训练动物所有已测刺激估计各神经元的共同尺度；每个神经元至少需要 2 只其他动物具有 A、B 的成对测量，且测试动物同时具有 A、B 的该神经元，才进入该次差向量。此次 45 对近邻的各次向量实际包含 6–13 类神经元，没有缺失补零。保留“全 atlas 起点”不等于强求每次测量都齐全或每类都有独立贡献。

若训练差向量为 t，留出动物差向量为 d，则 signed cosine = t·d / (||t|| ||d||)，signed projection = t·d / ||t||。projection 的尺度经训练神经元标准化，不能解释为原始 ΔF/F₀。表里的 same_direction 与上一轮 paired-assignment correct 完全相同；这只是同一个点积指标的解释改写，绝非新发现。它不需要对未知菌株做分类，也不检验神经是否能取代化学。

## 近邻与重复单位

用与 Notebook 一致的 380 项 log₂FC 的 RMS 差异定义化学距离。在同一采集块、菌属和化学参照组的可比较菌株内，为每株选最近邻并去重，得到 45 对、72 株、49 只动物、9 个采集块、255 条动物×pair 记录。每对有 4–7 只动物。这是相对近邻，不表示化学不可区分。17 对来自仅有 2 株的候选组，近邻身份自动成立，故必须单列候选组至少 3 株的子集。

生物重复单位是动物（采集块与 worm_key 联合身份）。同一动物可贡献多个 pair；不同 pair 可共用菌株；留一动物的训练集合也高度重叠。因此 255 条记录、45 对菌株、多个窗口或多个交叉验证 fold 都不是独立生物学重复。本次不做 p 值、显著性或独立验证声明。

## 看到了什么

主汇总先在每只动物内平均所有合格 pair 的同向指示，再对动物等权平均。它描述当前实验目录及协议内动物间差异方向的一致性，不能推广为新日期、新刺激顺序或任意新菌株的表现。

| 化学定义子集 | pair / strain / animal | 动物×pair记录 | 动物等权同向比例 | 去整体幅度后 | pair中多数/恰半/不足半动物同向 |
|---|---:|---:|---:|---:|---:|
| 全部相对近邻 | 45 / 72 / 49 | 255 | 80.0% | 79.2% | 41 / 1 / 3 |
| 候选组至少 3 株 | 28 / 40 / 38 | 166 | 81.4% | 79.4% | 26 / 0 / 2 |
| 同种相对近邻 | 14 / 28 / 44 | 78 | 77.3% | 77.7% | 13 / 1 / 0 |
| 互为最近邻 | 32 / 62 / 49 | 177 | 77.4% | 77.2% | 28 / 1 / 3 |

全 45 对中有 24 对所有已测动物同向，21 对至少有一只动物未同向。pair 等权比例为 84.2%，动物×pair 等权为 83.5%，与主结果动物等权的 80.0% 不同。不能混用这些分母。全记录 signed cosine 中位数为 0.347，按动物先平均 cosine 再动物等权为 0.287；同向不等于强烈或完整重现整个响应图案。

按化学距离预先选出的最近 A007/A010 只有 2/7 动物同向，pair 的 median cosine = −0.0995，是必要反例。第二近 A022/A023 为 6/6 动物同向；上一轮已查出其最大贡献主要为 ASK，且刺激顺序固定，所以不能以此例支持“全部神经元独立贡献”或“已排除非菌株原因”。单独找一张漂亮的平均曲线会遮蔽这些限制。

此外两对不足半动物同向的近邻为 A024/A025（2/5）与 A288/A302（2/5）；A289/A290 恰为 3/6。这些对在完整结果表中保留。

## 少数 pair 或菌株是否主导

对已经存下的逐动物向量做删除后重新汇总，不重估向量或尺度。这是评价集合敏感性，不是重新拟合后的外部验证，也不是置信区间。

| 删除方式 | 动物等权同向比例范围/结果 |
|---|---:|
| 每次删 1 对近邻 | 78.3–81.5% |
| 每次删 1 株及其全部 pair | 77.2–82.7% |
| 每次删 1 个采集块 | 78.2–83.4% |
| 删方向一致性最高的 3 对 | 78.7%（42 对、49 动物） |
| 删方向一致性最高的 5 对 | 78.5%（40 对、49 动物） |
| 删方向一致性最高的 10 对 | 77.1%（35 对、49 动物） |

“最高”的排序为 pair 同向比例优先、并列按 median cosine 排序。这是有意删去最有利证据的事后反证，不是预注册子组。结果表明总体方向一致性不依赖一两个成功示例；它不能排除所有 pair 共有的刺激顺序、环境或测量流程影响。没有跨日期独立验证。

## 独立计算核验

脚本没有调用原评估函数，而从 aligned_neural_animal_5bins.parquet 直接重建 45 对 × 所有留出动物的 population 和 gain_removed 向量，共 510 次。signed cosine 最大绝对误差 6.7×10⁻¹⁶；signed projection 最大绝对误差 5.4×10⁻¹⁵；原始全部 21,312 行指标的 cosine/projection 符号与 correct 一致；子集重算与旧汇总最大差为 0。输入及脚本 SHA256 见 response_evidence_verification.json。

可复用表均以 response_audit_ 开头：animal_pair_directions 保留逐动物连续值，pair_directions 保留全部成功和失败 pair，subset_summary / animal_summary 明确权重，deletions 记录每次删除的对象与覆盖，strain_incidence 显示共享菌株依赖。

建议主叙事使用“神经测量提供化学邻域内部的生理响应表型”，并以直接响应和正反例为主。方向一致性作为汇总支持，不再画成身份预测排行榜。当前证据不能证明其为化学无法测得的新分子信息、不能证明化学近邻等价，也不能证明这种补充信息已经关联行为或适应度。
