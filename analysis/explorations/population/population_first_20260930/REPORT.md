# 群体响应保留了哪些菌株差异？

本轮从完整13类神经元同时开始，研究对象是菌株引起的群体钙响应。此前ADF/ASH、ASI/ASJ等结果只用于事后比较，没有进入特征筛选、轴拟合或化学近邻选择。主线是群体响应的连续结构与局部感知差异，化学作为同一菌株的参考表征及可解释性检验。

## 群体差异能否在其他动物中重建？

### 多维连续结构可重建，坐标却不是固定生物模块

先对每动物、细胞、时间窗减去该动物接受的刺激集合平均值，研究同一动物内菌株对比，避免共有刺激反应主导问题。全部13×5坐标同时进入PCA；不使用菌属、化学或前轮细胞名单。主分析在训练动物内估计每细胞一个尺度，五窗共享；原单位及响应对比方向归一化作为敏感性。

200次按整动物同步拆半，每次22/27只分居两边并交换训练与测试。尺度、方向和菌株坐标都在训练半学习，再重建另一半。只评价两半均覆盖全部13类均值的菌株–采集块：每次73–99个，含70–93不同菌株；没有填零或用不同缺失集合识别菌株。

| 保留的群体方向数 | 细胞平衡重建R²中位数 | 拆分5–95%范围 |
|---:|---:|---:|
| 1 | 0.108 | 0.074–0.138 |
| 2 | 0.188 | 0.127–0.226 |
| 5 | 0.264 | 0.183–0.327 |
| 全65维 | 0.251 | 0.166–0.312 |

增加若干方向比一条方向更能重建其他动物的菌株差异，保留全部坐标没有继续改善。没有按测试最高点宣称“恰好五种神经程序”。范围是同一数据的拆分敏感性，不是200次独立验证的置信区间。R²以训练均值预测为基准，不等于稳定生物学方差的解释比例。

原单位下rank1/rank5为0.534/0.681，大幅度细胞影响更大；不同尺度改变误差权重，不能比较这些R²判断哪种表示科学上更好。对细胞缩放后的**居中响应对比**归一为单位向量，rank1/rank5仍为0.109/0.202。这控制的是对比向量长度，不表示原始钙响应的一切整体幅度因素都被排除。

### 由全群体自己定义对照，再回看实测响应

每次留一只动物，用其余动物的全部65维学习前两个连续坐标；训练方差决定顺序，最大绝对权重取正，没有用全数据参考轴对齐。按训练分数在该动物接受的菌株中选最高、最低各3株，读取测试动物真实曲线。每细胞两边都要求恰好3株，不能将两株与三株平均混算。

**核心图1：[全13细胞、5窗口的实测高−低响应](figures/population_structure_held_responses.png)。** 两方向共49动物，分别覆盖68/73不同菌株；每行细胞有39–49动物，图中注明。每格先在动物内计算两组三株均值之差，再在可用动物间平均；颜色和数字均为ΔF/F₀，两图共用色标，黑线为刺激结束。没有显著性星号或误差带。[每动物每格数据](tables/population_structure_held_animal_bin_contrasts.csv)及[分布汇总](tables/population_structure_held_animal_bin_summary.csv)保留不确定性和异常值。

第一方向可见ASK、ASI、ASJ、AWCON较高，ADF、ASH较低；与旧结果部分重合，但由本轮全群体拟合得到。第二方向10–25秒的实测差为：

| 细胞 | 高−低平均差，ΔF/F₀ | 同方向动物数 |
|---|---:|---:|
| ADL | +0.087 | 40/47 |
| AWA | +0.227 | 42/47 |
| ADF | +0.280 | 32/40 |
| AWCOFF | −0.139 | 39/46 |

这让弱响应细胞与不同AWC亚类进入群体表型，而不要求先将它们加入ADF/ASH模型。表中列举只为解释新方向，主图与拟合始终包含全部13类；它不证明各细胞独立的因果贡献。

**反证和降级。** 每次训练剔除对比范数最大的3个菌株–块，重新学尺度和方向，rank5 R²仍约0.242。首轮及后续trial分别重估的前两维子空间与trial均值近似，ADL/AWA/AWCOFF的第二方向贡献保留；0–40秒的rank1/rank5为0.100/0.232。

更严格地让两半动物**各自学习PCA**，方向一致性明显依赖缩放。共用训练尺度时第一轴方向cosine中位0.484；各半独立估计尺度再映射到共同尺度时为0.868。固定训练轴得到的较高菌株坐标相关，不能证明两半找到唯一相同轴；后续坐标更不稳定。因此保留“可重建的多维响应结构”，放弃“两个固定神经模块”和硬聚类。刺激顺序、动物状态及共同处理误差仍可能贡献，没有被数学模型完全识别。

精确支持集合见[选菌株记录](tables/population_structure_held_animal_selections.csv)、[近原始曲线](tables/population_structure_held_animal_curves.csv)。生成：[01脚本](code/01_population_structure.py)。[方向权重](figures/population_structure_axes.png)和[重建曲线](figures/population_structure_reconstruction.png)为附图；权重不是钙幅度，拆分带不是独立验证。

会降低信任的结果：独立动物或打散刺激顺序后，多维相对一维的重建增益消失，或新方向仅由异常株维持。当前已发现坐标不唯一，解释已相应收缩。

## 化学近邻内部，神经atlas还能提供什么？

### 全谱相对邻近不保证相同的群体响应

先在同采集目录、同菌属、同reference内定义147个可比菌株对，只用380项原尺度log₂FC的RMS距离选择每株最近邻；去重45对、72株，神经结果不参与选对。每次整只动物留出，由其他动物同时观察到的两菌株响应形成全可用细胞×5窗差向量，再检查留出动物的差是否同向。每细胞至少2只成对训练动物，缺失不填补。

这是已知两刺激各出现一次的**配对二选一**任务，机会水平50%，不是未知刺激多分类。每动物先平均自己的所有合格对，再对49动物等权，不能将共享动物和菌株的45对当作45个独立重复。

| 表示或反证 | 同一最近邻集合的配对辨认率 |
|---|---:|
| 全可用群体，训练内细胞缩放 | 80.02% |
| 去全局正幅度、保留群体方向 | 79.17% |
| 单一整体幅度 | 67.18% |
| 删除训练中差异最大的一个细胞 | 75.34% |
| 只保留训练中差异最大的细胞 | 75.85% |
| 首次trial训练→后续trial测试 | 72.45% |
| 后续trial训练→首次trial测试 | 72.45% |

覆盖255个动物×菌株对、49动物。80.02%的固定预测整动物重采样95%描述范围为75.77–84.10%；没有重训模型，不包含选择或未来采集条件的不确定性。共同细胞限制为81.29%，线性trial位置去趋势为81.80%；任意非线性适应及前刺激效应仍未排除。

最近邻必须限定为相对指标：45对RMS距离范围1.758–3.382，中位2.452，并非化学相同。17对来自仅两株的组，互为近邻并不证明接近；限制组内至少3株，群体仍为81.40%（28对、38动物），去gain79.39%，幅度65.15%。全部147对的距离最低四分位为80.99%（37对、40动物）。同species近邻14对、28株、44动物为77.27%。这些是明确的范围检查，并未按神经结果挑成功pair。

### 两个化学预选实例：同时保留成功与失败

**核心图2：[化学近邻的全13细胞动物内差异](figures/neural_value_paired_population.png)。** 两例为可比pair中化学距离最小和次小者，预先按化学选定。每点是一只动物的0–25秒平均响应差，黑短线是动物均值，无显著性标记；两图共用x轴，每细胞覆盖不同。判别保留五个窗口，并非仅用图中的25秒均值。[图数据](tables/neural_value_example_paired_differences.csv)。

- **A007/A010**：元数据为B. thetaiotaomicron / B. salyersiae，化学距离1.7581。7动物，每细胞3–7动物；群体2/7、去幅度3/7、共同细胞5/7，证据不稳。ADF仅3只且全部同向，单看该细胞会夸大支持。没有把不稳写成不存在响应差异。
- **A022/A023**：均标注B. stercoris，化学距离1.7944。6动物，每细胞5–6；群体、去幅度、共同细胞、首后trial互换均6/6。[全13类原曲线](figures/neural_value_chemical_neighbor_2.png)可检阅。

**成功例的关键反证。** 六个训练折最大差细胞均为ASK，ASK单独也6/6；删ASK后总体5/6、首→后4/6、后→首6/6。因此不能说此例需要全部神经元不可替代。同时所有动物都是A023先、A022后，平均位置差4；去线性位置趋势仍6/6也不能解除固定先行刺激的竞争解释。结论限于本采集协议的跨动物差异。

整体45对的最大差细胞随刺激比较变化，13类均有被选中的fold，ASER仅1次；这样的计数不证明每类细胞可靠贡献。[完整分布](tables/neural_value_largest_cell_distribution.csv)区分fold与pair层级，不将255次选择当作独立生物学重复。

**可以保留的价值：** 直接神经群体测量回答了这些化学近邻在当前实验中是否引起相似钙响应，增加生物体响应层面的表型。不能据此声称“LC–MS分不出”“神经测量更准确”或已识别感知/行为因果机制。缺少化学重复测量误差估计，本轮无法比较两种测量本身的可靠性。

## 化学与神经各自保留什么信息

### 相同外部任务下，化学更好地保留菌属标签

为避免预设“神经应当更好”，固定选择至少5株且跨至少3块的菌属，得到74株、8属、80菌株–块。相同目标、训练测试划分、类别平衡岭分类器和5个惩罚候选，比较65维神经与380维FC。神经用每块动物均值；化学仍不z-score。神经原单位和训练内每细胞缩放并列，不按胜负挑表示。

外层留整块，再从所有训练块移除全部测试菌株ID；内层同样处理。6个跨块重复菌株不被全局删除，保留相同对应关系；每株评估总权重1，重复按块等权。八个类别在每次训练中均存在。

| 表征 | 每属等权宏召回率 | 删一测试块的范围 |
|---|---:|---:|
| 完整380项log₂FC | 72.25% | 69.95–76.01% |
| 神经群体，原单位 | 49.99% | 43.22–51.92% |
| 神经群体，训练内细胞缩放 | 43.08% | 39.28–47.50% |
| 仅reference组标签 | 29.85% | 28.04–31.90% |

化学相对神经原单位的优势，删任一块后仍19.66–32.32个百分点。reference标签不能单独复现完整FC表现，但不排除所有培养条件影响。范围是固定预测的删除影响，不是置信区间。[对照附图](figures/shared_task_taxonomy.png)、[汇总](tables/shared_task_summary.csv)、[逐折审计](tables/shared_task_fold_audit.csv)；生成：[04脚本](code/04_shared_task.py)。

菌属是外部分类标签，并非行为或感觉功能真值。结果否定“神经在任何信息任务都优于化学”，却不否定神经atlas的响应表型价值。每属仅5–29株，本任务只代表这些菌属及覆盖。

### 相同FC仍未充分解释完整群体或低维群体坐标

化学回归首先预测全部13×5输出，不筛单细胞/窗口，每外层模型只有一个共享惩罚参数，由全部细胞平衡的内层风险选择。化学log₂FC除以共同常数√380，保持RMS几何，不逐特征z-score；加入reference，并比较整体水平、菌属及组合模型。106株全部保留，每层整块留出后清除训练中的测试菌株。

响应在动物内相对于其刺激集合居中，trial先平均。模型中每菌株总权重1；神经元与窗口只是同一次群体响应的坐标。评分使用测试菌株–块的动物均值，重复株按块等权。细胞平衡R²按训练细胞尺度加权，原单位另列。

| 输入 | 细胞平衡群体R² | 原单位群体R² |
|---|---:|---:|
| reference标签 | 0.042 | 0.042 |
| FC整体水平＋reference | 0.041 | 0.034 |
| 菌属＋reference | 0.074 | 0.071 |
| 完整380项FC＋reference | 0.023 | −0.007 |
| 菌属＋完整FC＋reference | 0.032 | 0.009 |

没有得到完整FC相对这些基线的整体增益。最后追加一项可能推翻此判断的检查：只预测每个训练折内部学习的主要群体坐标，避免把失败简单归于65维中的冗余或低方差噪声。预先固定rank3与rank5，不按化学表现改rank；每个内外层先清除测试菌株，再计算允许刺激集合内的神经中心化、尺度及加权PCA，避免中心化均值间接包含测试响应。

| 训练内学出的群体目标 | FC380＋reference R² | 菌属＋reference R² |
|---|---:|---:|
| 前3维 | 0.040 | 0.121 |
| 前5维 | 0.021 | 0.092 |

训练PCA分别保留约46.5%和61.9%的训练方差。降到主要子空间没有挽救该化学模型；高方差PC也不能自动称为已验证的可重复信号，因此未排除所有信噪问题。目标是各折自己的子空间，未强行将不同折PC编号解释成同一生物模块。测试化学也按已知测试刺激目录居中，因此预测的是给定目录内的相对群体表型，不是孤立新菌株的绝对响应。[低维预测结果](tables/latent_chemistry_summary.csv)，生成：[05脚本](code/05_latent_chemistry.py)。

这些阴性/弱预测限制当前表示、线性模型和留出范围，不能排除混合物非线性、遗漏成分或样本差异。不能将本轮与前轮分数差直接归因于FC变换：窗口、目标和重复株处理也变了。没有继续追加模型或筛单分子以追求阳性。

跨块化学预测与同目录跨动物神经重建的R²，**测试对象、基准与信息来源不同，不能直接相减来宣布神经更好**。双方真正相同任务的比较是菌属审计；感知差异证据来自实测响应及动物间转移。

## 证据边界与研究决策

所有路线重复使用既有数据。PCA方向、展示前两轴、rank敏感性、近邻定义和补充任务门槛均记在[RESEARCH_LOG.md](RESEARCH_LOG.md)。没有确认性p值、FDR或独立实验验证主张。日期用于身份、划分与核查，没有成为主图编码或科学结论。

可组织的叙事是：**完整群体响应形成连续、部分可重复的菌株表型；分类学和化学邻近不能替代直接测得的响应差异。** 化学在本任务更好地保留菌属标签，而响应表型需要自己的证据。不将神经数据说成普遍更优，也不把PCA坐标解释成受体、连接、抑制模块或放电时序。

最值得独立检验的是固定本轮群体指标，在能分离刺激顺序的记录中验证化学近邻是否仍产生不同响应。该实验及实际刺激化学剂量的外部核实未在本轮执行。代码、输入校验、运行状态与独立复核见[README.md](README.md)。
