# 群体响应优先：本轮检阅

**这轮从全部13类神经元×5个时间窗同时开始，没有固定ADF/ASH，也没有沿用之前选出的细胞组合。现有证据更支持将神经atlas定位为“菌株引起的群体钙响应表型”，而非菌属标签或化学距离的替代品。**

化学已严格对齐当前Notebook：106菌株×380项log₂FC，没有162项QC筛选、第二次加1、特征z-score或化学PCA预压缩。此前162是化学特征数，并非菌株数。神经侧也使用当前RSA相同的13×5个5秒窗，即0–25秒。Notebook关于“同培养条件、独立培养批次的spent-medium参考谱”的说明已纳入。

优先看三项判断：

1. **全群体存在多条可跨动物重建的变化方向。** 在训练动物内让各细胞有可比尺度，一条群体方向的重建R²为0.108，五条为0.264。第二方向涉及ADL、AWA、ADF增加及AWCOFF减少，拓展了先前围绕ADF/ASH的视角。先看[全13类细胞的实测群体对照](figures/population_structure_held_responses.png)。但两半动物分别学习时，坐标会旋转、交换且依赖缩放，不能把两个展示坐标命名为已验证的固定神经模块。

2. **化学近邻内部，神经响应仍提供细分表型。** 同菌属、同reference的45个化学最近邻对，留动物配对辨认率80.02%；去整体正幅度后79.17%，首次/后续trial互换均72.45%。[两个仅按化学距离选出的例子](figures/neural_value_paired_population.png)同时保留成功和失败：A022/A023同为B. stercoris，6只动物均可辨；更近的A007/A010则不稳定。A022/A023主要由ASK贡献，删除它后5/6，且刺激次序固定。因此支持协议条件下的响应表型差异，尚未独立识别纯菌株身份效应，也不意味着LC–MS“分不出”两株。

3. **神经的价值不在于普遍胜过化学分类。** 同74株、8属、相同整块留出并清除重复菌株的任务中，化学宏召回率72.25%，群体神经原单位49.99%，细胞缩放43.08%；仅reference标签29.85%。化学更好地保留本任务的菌属信息；但完整380项FC对整个神经响应的留出预测仍弱。只预测训练内学出的3维或5维群体坐标也未挽救：化学R²为0.040/0.021，菌属/reference基线0.121/0.092。详见[完整比较与边界](REPORT.md#化学与神经各自保留什么信息)。

**研究决策：将“可重复的群体响应结构，以及化学近邻内的感知差异”作为atlas的价值主张，不再从某两个细胞扩展成atlas，也不预设所有细胞都必须独立贡献。** 最值得检阅的是全群体产生的新响应对照和化学预选实例；最脆弱的是把连续坐标升级为固定机制模块，或把预测不足解释成化学没有作用。
