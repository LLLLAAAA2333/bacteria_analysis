# 化学近邻中的群体响应信息：已运行结果

## 科学判断

这一分析问的是：化学全谱中的相对近邻，是否仍有可跨动物识别的群体钙响应区别？不是证明神经测量比化学测量更准确，也不是比较两个全局距离矩阵。13类神经元同时进入起点，既未预选ADF/ASH，也未预先指定任一神经元模块。

在同采集目录、同菌属、同化学reference内可比的147个菌株对中，按完整380特征的RMS log2FC距离选择每株最近邻，去重后45对，72株、49动物、9采集目录，共255个动物内配对。全群体留动物配对辨认率80.02%，固定预测的整动物重采样描述区间75.77–84.10%；去掉全局正幅度后79.17%；单一整体幅度67.18%。群体减幅度的动物内差12.84百分点；精确区间和方向计数以`neural_value_comparisons.csv`为准，重采样不是独立验证。

首trial训练→其他trial测试、其他trial训练→首trial测试均72.45%；只用每目录所有动物均记录的细胞81.29%；线性trial位置去趋势81.80%。即同属/同化学reference近邻内部还有可重复的感知差别，并不由单一正增益完全解释。近邻是相对邻近，不是相同混合物；非零化学距离本身已包含差异，因此不能写成“LC–MS不能区分而神经可以”。

同species近邻作为更窄范围：14对、28菌株、44动物、78动物内配对；群体77.27%、去gain77.65%、幅度60.98%。这些对共享动物和菌株，不能将14或45当作独立重复样本做普通检验。

## 化学预先选择的两个例子，成功与失败均保留

1. 最邻A007/A010，B. thetaiotaomicron / B. salyersiae，化学RMS log2FC=1.7581。7动物，单cell覆盖3–7；全群体2/7，去gain3/7，共同cell5/7，首→后3/7、后→首5/7。此对的结论不稳。尤其ADF仅3动物且全部正差，单看这3只的ADF会夸大整体支持。结果不是“无响应差异”，而是该准则/覆盖未给出稳定群体判别。
2. 次邻A022/A023，同species B. stercoris，化学RMS log2FC=1.7944。6动物，单cell覆盖5–6；全群体、去gain、共同cell、首→后、后→首、线性顺序去趋势均6/6。全部13细胞原曲线和动物内配对差均保留。

A022/A023的关键反证：6个训练fold均选择ASK作为训练尺度下最大的差异cell。ASK alone也6/6，删除ASK后mean5/6、首→后4/6、后→首6/6、顺序去趋势5/6。因此这个例子支持生理区别，不能证明必须联合全部细胞，更不能作为分布式不可替代编码的例证。其ASK 0–25s平均配对差在6只动物均正，但其他cell也有同/异方向变化，见全体点图。

A022/A023所有动物都是A023先、A022后；首segment14/18且平均位置差4。首次/后续trial以及线性去趋势不能排除特定固定先行刺激、非线性适应或任意carryover。该例应限定为本采集协议中的跨动物一致性，不作为日期独立或因果菌株身份验证。

## 群体起点不等于每一个pair都需要全部cells

全45对的训练only最大差cell：255个动物×pair fold中ASK27、ADL20、ASI13、AWA23、AWB24、ASG31、ADF21、ASH32、ASJ31、ASEL6、ASER1、AWCON18、AWCOFF8。不同刺激比较的主要变化位置会切换，而不是固定ADF基座；ASER仅1次，不能因“都出现过”就断言每cell具有可靠贡献。

表`neural_value_largest_cell_distribution.csv`同时提供255 fold计数、该cell曾被选择的唯一pair数，以及45 pair众数计数（允许众数平局，合计51，非45）。这些计数只是选择覆盖，没有显著性意义。全体仅保留最大差cell为75.85%，删除最大差cell仍75.34%，全群体80.02%。不能用这几项概括为任一cell都不可缺，也没有寻找能最好辨认的单cell后强行与全群体比较。

## 方法和选择记录

- 化学输入精确使用本轮`aligned_chemical_log2fc_paired.csv`，106菌×380特征，与Notebook当前cell11一致，未做162/248 QC筛列、未z-score、未增加pseudocount。距离为`sqrt(mean((log2FC_A-log2FC_B)^2))`。表征中的原始填零/参考样本含义等局限见00的对齐审计。
- 神经表示精确对齐Notebook的13×5bin，五个5秒窗覆盖0–25s；与00的607×65表逐值核对，最大允许误差1e-12。其余25–40s未参与本线判别。
- 每一fold排除该动物的所有菌株与trial。训练动物所有刺激的5bin数值给每cell一个尺度，13cells无先验优先。对每个细胞只用同时具备两个菌株的训练动物构成模板，至少2只；测试动物仅用两株共同有记录的细胞。未填补缺失cell，未以每cell/每窗增加重复n。
- 训练均值A减B方向，与留出动物A减B向量点乘；正号判为正确匹配，零记0.5。是已知两刺激各出现一次的配对2选1任务，不是独立刺激识别。每个动物先汇总其所有合格pair，再等权汇总49动物。
- 去gain：先得同cell面板的两类训练均值模板，再分别除其RMS；测试两向量同理。保留符号和相对幅度，不等同纯三态响应。幅度对照只用相同模板和测试向量的RMS。
- 最大差cell只在训练均值差中选择：训练尺度下5bin平方差之和最大。删除该cell或仅保留该cell之后在留动物测试，无测试结果参与选择。
- 线性顺序敏感性：每动物×cell×bin在所有trial上拟合segment_index线性斜率并扣除居中位置趋势；保留动物整体均值。这只是去趋势，不识别前一个刺激的任意作用。
- 2000次block内整动物重采样，随机种子2026093022。区间固定已有预测、不重新训练，也不处理探索选择，因此仅描述已有采样覆盖，没有p/FDR/独立验证主张。
- 一次实现选择被修正：最初要求每个训练动物完整具备当前测试动物全部cells，导致原本49动物仅32可评价。改为每cell成对均值模板、模板后归一化；这是处理缺失面板以避免完整病例选择，随后保留每目录共同cells作敏感性。没有按神经表现改变选pair规则。
