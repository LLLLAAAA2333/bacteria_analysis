## 实际检查

1. 化学选择只依赖 380 维精确 log₂FC、同菌属、同 reference 及同采集目录下可配对的覆盖。`define_pairs` 不读取神经响应数值；最近邻、互近邻、全可比集化学距离最低四分位都在任何神经预测前定义。前两个示例按化学 rank 1/2 选择，成功与不稳定例都保留。没有以最大神经分离度筛 pair。
2. 每个测试 animal 的全部刺激都从尺度估计和模板拟合剔除。每个 cell 要求测试 animal 同时有两刺激，且至少 2 只训练 animal 有完整两刺激五个 bins；训练模板每个 cell 仅用成对训练 animals，不用缺失值或身份特异插补。共同 cell 敏感性另要求目录内所有刺激和动物都有该 cell。
3. `gain_removed` 先形成每株训练均值向量，然后在同一 cell 面板上分别做 RMS 归一化；测试两向量用相同面板。`magnitude_only` 使用完全相同尺度和模板。没有先按每只动物不同面板归一化再拼模板的错误。保留相对幅度和正负号，所以应称去正增益的组合，而非纯离散响应类型。
4. 不调用被复核的 `evaluate`，独立从本轮 `aligned_neural_animal_5bins.parquet` 重建每 fold 尺度、成对均值、测试差和三种主表征。全部 **2664 个 animal-pair-mode** 的正确标记与表格一致，最大差 0。
5. 从表格核对 mean/nearest-either 主分析：45 对、72 株、49 真动物、255 animal-pair；先在动物内平均其 pairs 后再对动物等权平均，群体 0.800170、去增益 0.791667、幅度 0.671769。模式观察集合匹配，未把 255 pairs 当成 255 独立动物。
6. 最近邻规则在组大小 2 时必然纳入唯一一对，这部分有 **17/45 对、89/255 animal-pairs**，因此“最近”不等于绝对化学相近。现有反证足够区分：组≥3 的 nearest 是 28 对、40 株、38 动物，群体/去增益/幅度为 0.814035 / 0.793860 / 0.651535；距离最低四分位 37 对、40 动物为 0.809924 / 0.805758 / 0.663561。建议主报告明确这两项，避免只强调 45 对。
7. 主图动物内差数据是两株皆有观测的动物。独立核对两例每 cell 的原曲线覆盖、主图点数及标题范围：A007/A010 两株均为 3–7 动物/cell，A022/A023 两株均为 5–6；当前没有不匹配 group mean 伪装配对的情形。主图共用 x 轴，灰线为零，黑 tick 为成对均值，已视觉检查无标签截断或反向 y 轴问题。
8. 图中 0–25 秒均值只是原单位展示；实际判别仍用分开的 5 bins。总览和方法已明示这一点。所有 13 cell 在原曲线与点图展示，没有强行隐藏负例细胞。

## 解释边界与非阻断提醒

- 化学距离都大于零；最小约 1.76 RMS log₂FC，不能称“相同化学样本”或“LC–MS 无法区分”。本线没有化学生物重复，无法估计化学辨别准确率，更不能拿神经 80% 与某不存在的化学准确率比较。
- 最近邻对限制同 reference，log₂FC 差中的共同 log₂(reference) 在代数上抵消；因此这个子问题的成对化学距离与同样 pseudocount 的报告值 log 差一致。这是限制同 reference 的数学结果，不妨碍按用户要求与 Notebook 对齐，但不能声称该近邻结果本身证明 FC 优于 log 报告值。
- 49 folds 的训练数据大量重叠，pairs 也共享菌株。现有区间是 block 内整动物重采样固定预测的描述性范围，不是重训练后置信区间或选择校正的显著性结果；报告没有 p/FDR 论断，符合限制。
- A022/A023 的 ASK alone 6/6、删 ASK 后 5/6，证明这个例子可以有主导细胞，不能据此声称每个菌株对都要求多细胞联合。总体“largest cell”由训练差幅度选择，不是嵌套挑出的最佳预测单 cell；比较结果不能夸大为优于所有单细胞解码器。
- 首/后 trial、线性顺序去趋势是有意义的敏感性，但固定刺激顺序和特定前序刺激仍不能完全区分。A022/A023 的顺序关系在记录中已坦诚说明，应在主报告保留。

无须为本复核增加模型或重复全部分析；主要交付动作是维持以上适用范围，并在摘要中避免“化学不能区分”与“每个 cell 都不可替代”的表述。
