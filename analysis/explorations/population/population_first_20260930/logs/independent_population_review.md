# 独立只读复核：全群体结构分析

复核对象：`code/01_population_structure.py`、其全部方法/结果摘要、关键导出表。未修改作者的代码或结果，未重复运行200拆半；进行了代码走读、全部重建R²的算术核对、全部留动物原曲线的来源重建，以及49次轻量leave-animal轴方向诊断。

**结论：未发现阻断本轮描述性科学结论的实现错误。** “群体变化有多个可跨动物重建的方向”有计算支持；“独立验证了两个固定生物模块”“确切需要5个神经程序”或“这证明每个细胞都不可替代”均不被这些结果支持。现有`population_structure_findings.md`已经明确这些边界。

## 关键检查

1. **拆分单位正确。** 每采集目录随机拆分整动物，全部刺激、cells和时间窗跟随动物同步。每次22/27动物，交换训练/测试方向。animal×cell×bin在本动物刺激集合内先中心化，未把其他动物的测试响应用于训练均值；但该操作确实利用测试动物自身完整候选刺激集合定义对比，因此不是未知单刺激或新菌株预测。
2. **PCA拟合与预测确实训练only。** 两半均值之后，训练半估计cell尺度、中心与SVD；训练strain-block坐标给出低rank重建，再直接对比测试半对应strain-block响应。全数据ref仅进入描述性轴图和子空间对齐诊断，不进入主重建或留动物高低组选择。score correlation是同一训练轴在两半的坐标一致性，不是独立PCA loading一致性，报告已区分。
3. **缺失覆盖真实且有损失。** 每次必须两半都含全部13cells，不插补。导出覆盖73–99 strain-blocks（中位88），70–93菌株（中位85），6–8采集目录（中位7）。这意味着重建不是每拆分覆盖全部106株/9目录。112全目录描述轴包括6个重复菌株的两块条目，不能把112当独立菌株；报告已写明。
4. **重建算术正确。** 全部`1-test_sse/null_sse`与记录的R²最大差4.16e−16；中位、5/95分位与summary最大差8.33e−17。归一化目标与未归一化目标有不同误差权重，三个R²数值不可直接排名为哪类表示更科学。
5. **异常菌株检查真正重新拟合。** 最大3个训练response-contrast范数定义剔除对象，随后重新估计尺度/PCA，在保留集合评估；普通拟合也在同集合和robust尺度下重计。direction目标改变尺度后的非线性归一化不可简单换算，代码将matched普通对照设NaN，未错误比较。此结果抵抗少数极端点，但不是新菌株验证。
6. **近原始直接证据没有测试选择泄漏。** 每次完整排除held animal，训练全部65维，按训练方差排序轴、以最大绝对loading定符号；仅依训练分数在测试动物曾接受的刺激中挑高3/低3。逐组核实全为3株，组间无重叠，每fold只来自测试动物自己的采集目录；未发现1/2株残缺组。按选择表从原`animal_curves.parquet`独立重建全部导出高/低曲线，最大差8.88e−16。
7. **轴唯一性没有被高相关伪装。** 两半各自PCA、各自估计尺度和共同尺度的principal-angle诊断属于拟合敏感性；包含全数据的共同度量与参考存在数据重叠，不能提升为独立证据。尽管完全独立拆半会旋转，leave-one-animal的高低图本身没有发生明显轴符号交换：另行诊断49个leave-one-animal轴与全数据轴在共同响应尺度下cosine，轴1最低0.99593、轴2最低0.99432。这里只检验图中跨fold汇总是否混合了相反方向；该参考不参与原选择，也不构成独立验证。
8. **首次/后续trial检查范围正确。** 它重新构造群体坐标并比较子空间，但full-data参考包含这些trial，且固定顺序未改变。因此可抵抗简单“只有后续重复制造组合”的解释，不可称跨实验稳定或排除特定顺序/前刺激作用。

## 需在主报告保留的限制

- 49fold训练集合高度重叠，49×13×5不是独立生物学n，200split只是同一数据的拆分敏感性。
- 图的两个高低组是每动物候选集合中的连续坐标两端；不同动物选择的菌株可不同，不能命名为固定两个菌群类别。
- 方向归一化是对本动物刺激集合中心化后的对比向量进行，而不是从原始钙响应中完整移除所有正gain。
- 全群体起点成立，但轴能量仍允许某些cells占较大权重；这不证明所有cells同等重要或存在神经元相互作用。
- 精确时序与放电机制未被核实。五个bin主分析覆盖0–25s，以与RSA一致；0–40s仅是既定敏感性。

焦点算术和覆盖核查记录见`independent_population_arithmetic.json`；49fold方向诊断逐值见`independent_population_loo_orientation.csv`。这些都是审计诊断，不是新增挑选结果的步骤。
