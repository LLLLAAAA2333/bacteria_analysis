# 群体化学预测的独立只读复核

复核对象：`code/03_population_chemistry.py` 与本轮实际运行输出。复核者未编写或修改该脚本。依据是当前 aligned 输入；额外采用独立的 sklearn SVD Ridge 实现比较预测数值。

结论：**未发现需要阻断本轮结论的计算或交叉验证泄漏问题。** 该结论限定于实现与当前已运行数值，不能消除菌株与采集块的设计限制，也不能提升为独立实验验证。

实际执行的核对保存于 `independent_review_checks.json`：

- 共 81 个外层/内层划分。每折训练与测试菌株集合、真实动物集合均无交叉；跨块重复菌株已从相应训练折清除。
- 5 类模型、106 个菌株；每株都有完整 65 个群体输出目标。缺失动物内神经元直接省略观测，不作零填补。
- 每个模型、菌株、神经元、时间窗的最终动物权重总和为 1，最大误差 4.44×10⁻¹⁶。
- 直接从 aligned 65 列、按 `(date,worm_key)` 重建动物内中心化目标，与全部 176,575 个预测输出行的 observed 相符，最大误差 8.88×10⁻¹⁶。
- 每个外层模型只选择一个用于整个群体的 λ；保存选择均等于内层全部神经元/时间窗风险的最小值，不使用外层测试损失调参。
- 全部群体 R² 独立重新汇总，最大误差 3.38×10⁻¹⁶。
- 独立重拼训练/测试输入、权重、目标并用 sklearn `Ridge(solver='svd', fit_intercept=False, alpha=λ×sum(weight))` 复拟首个留出块。两模型（fc380、genus_reference）× 三个神经元（ASK、ADF、AWCON）共 6 个拟合，与保存预测最大差 9.30×10⁻¹⁶。

解释时需要保留的区别：

- 所有 13 类神经元从一开始都是目标，共享群体选择的正则强度；由于缺失观测不同，各神经元的系数分别拟合。这是全群体目标评价，并不是已证明一个统一潜变量或固定生物学模块。
- 目标是某动物实际测得刺激集合内的相对响应；测试目标中心化用于定义待预测量，不代表模型获取单个新刺激的未知响应均值。结果不能直接改写成新实验的绝对 ΔF/F₀ 预测性能。
- cell-balanced 风险和 raw 风险都要保留；前者不是更多独立生物学重复，后者可能由幅度大的通道影响。
- 只报告外层结果；内层筛选不属于独立验证，删除株/块的固定预测检查也不是新实验或置信区间。

两个低优先级改进均已解决：

1. 初审时脚本加载旧轮 taxonomy/reference 表，而新轮已有对应 aligned 表。已核对实际使用的 genus/reference 字段严格一致。主 agent 已改为 aligned 输入，减少旧文件依赖；数值不变，无需重拟合。
2. 初审时删除采集块影响检查保留原 block_weight。主 agent 已添加 `deletion_scores`，每次删块后按剩余观测重新计算每菌株等权，并使用保存预测实际重算影响表；主群体分数不变。代码更新已只读确认。

共同菌属比较的核对另见 `shared_task_verification.json`。该辅助任务的化学优势不能改写为总体测量优势；菌属不是行为/感知功能的真值。reference-only 基线不足以复现完整 FC 性能，但不能排除所有培养条件影响。
