# 更多神经元如何参与菌株响应，化学能解释到哪一步？

本轮延续上一轮已经获得的“细胞配比比整体增益更有信息”，实际检验其余11类神经元的补充作用，并尝试从化学组成重建新增群体表型。结论停在证据支持的位置：**神经响应存在可扩展、贡献不均的组合；化学与群体响应有部分对应，尚未得到可命名、能解释属内差异的化学机制。**

## 数据及本轮能推广到的对象

复用已校验的动物与trial曲线，没有重提取荧光或改写原始数据。全神经数据106菌株、49只动物、9个采集块、607动物×菌株、7,063动物×菌株×细胞曲线。动物身份是日期与worm_key的组合；trial先在动物内平均，双侧细胞依既有流程合并。缺失细胞不填零。

刺激期用0–9秒十个采样点，post用10–29秒二十个点。单位均为存储的钙信号ΔF/F₀。post只是相对于刺激的观测时间段，不能直接解释为放电OFF响应、抑制性连接或精确神经动力学。核定位GCaMP6s/7s及处理信息依据项目已有记录；本轮没有独立核查原始成像标记或拟合新的动力学模型。

两种推广目标严格分开：

| 分析 | 观测与重复单位 | 可回答的问题 | 不能据此声称 |
|---|---|---|---|
| 神经辨认、群体响应选择 | 动物内trial平均；整只动物留出 | 已测刺激目录的差异能否转移到别的动物 | 未见菌株/新日期的独立验证 |
| 化学预测 | 每动物×菌株×细胞；同菌株总权重1；整块留出 | 未用于拟合的菌株和动物，其相对响应能否由菌株级化学报告预测 | 化学样本就是实际刺激浓度、菌株与采集条件已完全解耦 |
| 属内化学检验 | 同动物同菌属至少2株的差异 | 化学是否细分菌属内部 | 任意菌属均有足够样本 |

只有6株跨两个日期重复，全部属Bacteroides，不能用它们代表整个atlas的跨日期验证。化学模型为确保训练和测试菌株完全不重叠，统一排除这6株，得到100株、49动物。化学对照需五细胞和全部选定菌株齐全时进一步降到16动物；报告不把它与32动物的完整神经结果混算。

LC–MS按菌株ID对应；未核实与神经刺激同培养批次、同上清制备或同剂量。主面板162项为QC RSD≤0.30且全部配对菌株完整的报告特征；248项敏感性面板允许至少90%检出，缺失仅用训练集的中位数填补。报告中的ng/mL不能当作虫体接触的分子浓度。没有空白、上机顺序、生物学复测、标准品和MSI注释等级等充分资料；异构体/共洗脱与相关特征不能当作独立分子证据。历史reference group作为干扰变量，未把其不明生物学身份当机制。

输入校验及环境见[清单](logs/input_manifest.json)和[环境](logs/environment.json)。原始LC–MS与神经数据的既有处理审计保留在上轮目录，本轮只补做影响本轮判断的检查。

## 问题一：ADF/ASH之外的信息来自哪些细胞？

### AWA与ASK补充信息，并且不只是菌属标签

每神经元用stim与post两个坐标。其他动物形成每菌株响应模板，整只测试动物及其所有菌株同时留出，候选为同一刺激目录。所有比较匹配动物和候选菌株，每细胞每菌株至少有2只训练动物；可见性随动物变化，因此“全atlas”准确地说是全**可用**细胞集合。

| 匹配比较 | 原始响应向量 | 负/近零/正三态 | 覆盖 |
|---|---:|---:|---|
| ADF/ASH → 全可用atlas | 33.72% → 49.35% | 21.78% → 35.76% | 40动物、106株、499动物×菌株 |
| ADF/ASH → 加AWA、ASK | 33.99% → 46.01% | 22.11% → 34.59% | 39动物、106株、486动物×菌株 |
| 同属候选：ADF/ASH → 加AWA、ASK | 46.63% → 52.83% | 31.78% → 44.14% | 34动物、45株、229动物×菌株 |

三态阈值固定±0.05 ΔF/F₀，另报告0与0.1的敏感性，不挑最优阈值。这不是统计显著响应或真实放电状态。三态表现低于完整向量，故本轮证明的是“额外信息不全依赖精细幅度”，不是“所有幅度信息都无价值”。并列模板按均匀随机选择的期望正确率计分，避免菌株名称排序制造结果。

单独增加AWA，原始向量/训练标准化/三态增益为7.03/5.75/8.13个百分点；增加ASK为5.94/5.36/5.07个百分点。四细胞组合由这个探索选出，不是预先锁定的独立验证结果。完整atlas相对四细胞的额外增益较小：原始向量3.62个百分点、三态1.69个百分点，不能以此要求其余细胞等量参与。

**最强替代解释与反证。** 如果额外信息只是菌属标签，限定同属后应该消失；它没有消失。该子集Bacteroides较多，去掉后增益仍为5.95/12.76个百分点，但只剩21动物、72观察，不能推广到所有属。首次trial训练→后续trial测试，四细胞原始/三态增益6.08/8.30个百分点；反向8.89/11.19。去除每动物每细胞对刺激位置的线性趋势后仍为10.16/13.32。完整坐标要求下也保留，但覆盖降至16动物、37株。这些检查挑战了纯属标签、单次响应和简单线性顺序解释；共同刺激日程与非线性携带效应仍未识别。

**会降低信任的结果。** 后续随机刺激顺序、未参与选择的动物中，AWA/ASK增益消失，或该增益只由某个菌属/异常菌株维持。当前结果不赋予四细胞充分性、唯一性或已验证机制。

贡献审计附图：[加一个细胞与删一个细胞](figures/atlas_roles_incremental.png)。灰点是每动物配对准确率变化，彩点为均值，横线为固定预测下同块重抽动物2,000次的95%分位范围；不是重训算法的置信区间。每行标动物数，31–40动物、93–106株、383–499动物×菌株。原始向量、训练标准化、三态使用同一比较尺度。数据：[逐动物结果](tables/atlas_roles_animal_accuracy.csv)、[配对比较](tables/atlas_roles_matched_comparisons.csv)、[同属配对](tables/atlas_roles_within_genus_paired.csv)；生成：[01脚本](code/01_atlas_roles.py)。

## 问题二：较小响应的细胞是否也参与可解释的群体变化？

### ASI/ASJ共同变化，并伴随未参与选组的ASK变化

先在13类细胞的78对、stim/post/full三个窗口筛查相关与一致性，才选中post的ASI/ASJ继续检验。因此细胞对和窗口都是发现性选择。它不是唯一共变组合：post中ASK/ASJ的居中菌株相关约0.475，ASI/ASJ为0.464，ASK/ASI为0.331。分析只支持多个细胞共享一部分菌株响应差异，不推断解剖连接或同步放电。

为把相关变为可看见的现象，每次留出一只动物，用同目录其余动物的ASI/ASJ平均post响应选最高、最低各3株；测试动物的响应不参与排序。再要求五类细胞同时可见，得到32只动物、63个不同菌株、8个采集块。高组相对低组为：

| 神经元 | post平均差，ΔF/F₀ | 与平均方向相同的动物 | 参与选组？ |
|---|---:|---:|---|
| ASI | +0.0693 | 28/32 | 是 |
| ASJ | +0.1261 | 29/32 | 是 |
| ASK | +0.0837 | 25/32 | 否 |
| ADF | −0.1950 | 24/32 | 否 |
| ASH | −0.1368 | 24/32 | 否 |

核心图：[五细胞的实测响应](figures/response_patterns_asi_asj.png)。所有细胞用同32动物、同一折高低菌株；曲线来自动物内trial均值，再在每组三株平均，显示存储的−5到39秒钙信号。每只动物同时贡献一条高组和一条低组曲线；细线展示动物分布，粗线为动物均值，灰区为刺激0–10秒。五面板共用纵轴；没有平滑、误差带或把小幅细胞缩放为与ADF等幅。数据：[匹配曲线](tables/response_patterns_matched_five_curves.csv)、[逐动物差值](tables/response_patterns_matched_five_contrasts.csv)、[每折菌株身份](tables/response_patterns_held_assignments.csv)；生成：[02脚本](code/02_response_patterns.py)。

**真正的反证。**

- 共享动物的共同噪声：用一批动物的ASI菌株排序对应留出动物的ASJ，38折中36折为正，中位Spearman 0.378；反向32/38为正，中位0.253。故不完全依赖同一动物两细胞同时波动。但共享刺激日程依然存在。
- 少数异常株：去A247，ASI/ASJ居中菌株相关从0.464变为0.448；去三个绝对评分最大株后0.406，非单株制造。首轮及后续均弱于全trial平均，说明个体波动和trial平均确实影响清晰度。
- 统一幅度增益：对五维响应拟合一个共同正增益，残差仍较大。原点单位长度归一化后ASI/ASJ/ASK仍在28/29/26只动物升高，ADF/ASH下降只剩18/20只。**因此不保留两个固定对立模块的解释**；较可靠的是三个小响应细胞所占配比增加，而ADF/ASH绝对均值减少包含整体幅度贡献。
- 分类学构成：高组含19个菌属，低组富集Bacteroides和Bifidobacterium。限定同属重新选组后五细胞模式不普适，例如Escherichia中ADF方向反转。ASI/ASJ共变可在属内描述中保留，但“固定五细胞对立”不能由此推出。

基线扣除检查与原结果相同，是上游已扣基线造成的代数检查，不算独立稳健性证据。时程只取宽窗口；没有从该结果推断精确ON/OFF编码或放电时序。

**会降低信任的结果。** 新动物的ASK不再跟随训练中ASI/ASJ分组，或随机刺激顺序后群体差异消失；跨菌属重新匹配后变化方向不一致，也会降低普适模块解释。目前已发生后一种降级，故只保留目录条件下的群体响应候选。

## 问题三：化学组成能否重建这项群体变化？

### 有部分方向信息，尚缺少具体、可迁移的化学解释

上一轮统一正则化参数可能压制小响应细胞，本轮改为每细胞每窗口在内层整块留出中选参数。主比较预先固定六种表示：化学水平/reference、再加菌属、162完整面板、扣样本中位z的相对组成、248特征敏感性面板，以及菌属加162面板。另用可解释的9个化学Class覆盖129项，分别保留组内两个PC或相对组成四分位数；变换、填补、PC和正则化均仅在训练折学习。没有按单物质p值筛选。相对162表示仍保留水平项，与原面板主要是参数化和岭惩罚的改变；它不能独立证明“排除了总体水平，只由组成解释”。

神经目标与预测都在动物内相对于其测得刺激集合居中；每菌株每细胞总权重1。外层9块，内层8块；训练测试动物和菌株不交叉。R²以未参与训练的菌株平均相对响应为单位，基准为预测零差异。它不等于解释稳定生物学方差的比例，也不证明采集条件与菌株完全解耦。

| 目标 | 162面板R² | 248面板R² | 菌属＋化学水平基线R² |
|---|---:|---:|---:|
| ASK刺激期 | 0.109 | 0.146 | 0.041 |
| ASJ刺激期 | 0.093 | 0.121 | 0.062 |
| ASI/ASJ共同post均值 | 0.136 | 0.128 | 0.052 |
| AWA刺激期 | −0.057 | −0.052 | 0.025 |

ASI/ASJ轴由共同测量的两细胞物理单位均值构成，非另拟合的最佳潜变量。删去任一测试块，162面板的轴R²仍0.107–0.165，删任一株0.110–0.156；这些是删除敏感性范围，不是置信区间。ASK/ASJ在首轮及后续目标上有部分预测信息，ASI对后续trial的post单细胞预测不保留，不能把联合分数说成两细胞各自都解释良好。

为了直接对应神经现象，使用完全相同的高低菌株与共同动物评估化学预测，不从化学模型挑有利菌株。严格覆盖仅16动物、33个不同菌株、4块，32动物的完整神经图不能直接充当这个化学子集的实测值：

| 神经元 | 16动物实测高−低 | 162面板预测高−低 | 菌属＋化学水平预测 |
|---|---:|---:|---:|
| ASI | +0.0897 | +0.0185 | +0.0224 |
| ASJ | +0.1512 | +0.0207 | +0.0043 |
| ASK | +0.1081 | +0.0260 | +0.0159 |
| ADF | −0.1395 | −0.0510 | −0.0517 |
| ASH | −0.1907 | −0.0645 | −0.1987 |

五个平均方向均一致，新增ASK/ASJ有比菌属基线多的信息，但预测幅度收缩明显，ASH用菌属基线反而更接近实测。不能用“方向都对”替代精确重建，也不能把正则化收缩完全当成无生物关系。

对照图：[实测与化学重建](figures/population_bridge.png)。单图只回答同一群体变化被重建了多少；灰点为16动物的实测差，黑/橙/蓝点为实测、162面板和基线的均值。线为固定分组与预测下同块重抽动物2,000次的95%分位范围，**预测侧的窄线不包含重新拟合模型的不确定性**。单位ΔF/F₀，post为10–29秒。数据：[逐动物差](tables/population_bridge_animal_contrasts.csv)、[汇总](tables/population_bridge_summary.csv)、[菌株/菌属构成](tables/population_bridge_membership.csv)；生成：[07脚本](code/07_population_bridge.py)。

### 最关键的化学反证没有通过

如果模型抓住可解释菌株细节的组成特征，那么在同动物、同菌属内部应仍能排序。67株、8块的属内检验中，ASI/ASJ post轴162面板R²为−0.096，248为−0.157；相对组成也为负。进一步只用训练动物的属内差异重新拟合，162/相对162仍为−0.103/−0.087，ASK post为−0.130/−0.098。**将训练目标改为属内差异后，仍未获得可泛化预测证据。** 这没有识别原模型失败的原因；属内样本量、特征范围与模型假设仍可能限制效果。 可解释化学类PC/分位数对全部菌株ASI/ASJ post轴R²为0.0318/0.0250，低于菌属基线0.0523；原模型属内评分−0.0404/+0.0004，直接属内训练后−0.2335/−0.1014，同样未补齐这项证据；完整数值见[化学类结果](tables/chem_profiles_axis_scores.csv)与[直接属内拟合](tables/chem_profiles_within_fit_scores.csv)。

这是对“现有化学组成已经解释了新增群体表型”的实质性否定，而不是对所有化学作用的否定。现有panel可能遗漏真实有效分子，或报告样本与刺激暴露不匹配；非线性混合、培养介质、pH等也可能重要。本轮没有这些变量的充分数据，不能逐个指定为原因。

**目前没有把任何单物质、PC或化学Class升格为机制。** 组内PC和分位数保留了部分复杂组成，仍未给出可迁移属内解释；从失败模型挑几个漂亮loading不能补足证据。已有PC模型的贡献分解中，Phenols注释类（3-Methoxytyramine、p-Cresol、p-Hydroxymandelic acid）对ASK/ASJ有+0.0065/+0.0049的小幅同向项，但只占实测差的一小部分，另一类别表示对ASK甚至没有保留方向。这是弱模型线索，不能归因到该组或其中任一分子；[贡献表](tables/chem_profiles_bridge_class_summary.csv)保留完整结果。最有区分力的后续验证应锁定已有神经组合，使用匹配刺激制备的化学测量与能改变预测的混合物/组分操作，而不是继续从本数据筛更多单分子关联。

## 13类神经元如何放在同一研究图景中？

| 细胞 | 本轮支持的角色与边界 |
|---|---|
| ADF、ASH | 菌株响应主差异的一部分；不能单独覆盖全部组合信息 |
| AWA、ASK | 最一致的额外辨认信息；ASK也跟随ASI/ASJ分组，AWA化学预测未建立 |
| ASI、ASJ | 小幅但跨动物可见的共同变化；ASI的独立辨认增益有限，共变不等于连接 |
| AWB、ASER、AWCOFF | 共有阶段响应突出。以±0.05为描述门限，AWB有59/106株负转正；ASER刺激期104/106株负；AWCOFF有81/106株两阶段均负。共有响应不等于菌株特异性编码，也可能包含共同液流/成像因素 |
| AWCON | 幅度异质性大，贡献依赖缩放；本轮不足以给出普适化学解释 |
| ASEL | 刺激期多数菌株负（76/106）；尚未获得稳定附加辨认证据 |
| ADL、ASG | 当前指标下响应较小、附加信息不持续；不等于没有生物功能 |

此表让全部细胞接受同一证据标准，不把“atlas完整”误写成“每类神经元在每项任务中都不可替代”。描述门限没有生理阈值含义。数字与动物覆盖见[全细胞角色表](tables/response_patterns_general_roles.csv)。

已运行全部报告所依赖分析，保存逐观察预测、菌株身份、参数、种子、图数据及脚本。独立复核与输入校验见[复核记录](logs/independent_review.md)、[验证状态](logs/verification.json)。没有修改原始数据，没有调用外部数据上传/付费服务，没有补做未经授权的实验。未完成的是实验性的化学机制验证与刺激样本身份的外部核实，而不是隐藏未运行的计算。
