# 化学类别组成能否解释新增的神经组合

**没有得到可命名、可推广至同属菌株差异的化学类别解释。** 两种有明确构造的化学类别表示没有优于菌属/整体水平对照解释ASI/ASJ刺激后共同响应。将训练目标也改成同动物、同菌属的相对响应，仍未挽救ASI/ASJ或ASK；因此不把失败简单归咎于原来的训练目标主要捕捉属间差异。

这里的阴性结论只限制已执行的两种类别表示和岭预测，不能推出没有化学作用。化学参考谱只按菌株ID对应，尚未证明等同神经实验刺激液。

## 实际测试及范围

100株、49只动物，排除全部6个跨实验块重复菌株；9个实验块外层留一、其余8块内层留一。原始处理、动物内trial平均及缺失细胞处理沿用已核验表，观测目标为每只动物每细胞内相对各菌株均值的ΔF/F₀。每株、每细胞、每块的动物权重和为1，不把trial当独立样本。

162项complete-QC注释中，9个报告Class含至少3项，共129项。只采用两种表示：

- 各Class在训练菌株中拟合两个PC，保留同一类别内可反向变化的成分；共18轴。没有把61项羧酸衍生物直接解释成一个生理通路。
- 各特征log₂(report+1)用训练均值/SD标准化，再减去每株162项的中位z，计算各Class的25%、50%、75%分位数；共27项。这是相对报告谱描述，不是分子摩尔比。

两种表示均加入整体报告水平与参考组，并分别检查加入菌属的版本。每个细胞/窗口分别在内层以原单位加权MSE选择λ∈{.01,.1,1,10,100}；未用外层结果选择最优表示。刺激[0,10)、刺激后[10,30)、全[0,40)秒均保存，但ASI/ASJ刺激后目标来自独立的神经探索，不因化学拟合好坏改窗口。无确认性p值、FDR或独立实验验证。

## 与神经主线直接对应的结果

下表R²均对先平均到菌株的相对神经响应计算；零基准为无菌株相对差异。ASI/ASJ为同一动物同时测到两类细胞后的物理单位均值。

|ASI/ASJ刺激后目标|Class PCs|相对Class分位数|菌属＋整体水平|
|---|---:|---:|---:|
|全部100株、9块|0.03183|0.02503|0.05231|
|同动物×菌属重新中心、67株8块|−0.04041|+0.00041|0.01520|

加菌属后的Class PCs/分位数在全部100株为0.03683/0.02693，仍未改善菌属对照。整体40秒Class PC轴表现稍高，但不据此更换神经主问题或称为化学验证。

**可推翻“原训练目标受属间差异支配”的检查。** 仅保留同动物同菌属至少两个刺激，训练和测试的化学X与响应Y均在同动物×菌属内中心，锁定ASK刺激/刺激后及ASI/ASJ刺激后三个神经目标。67株、43只动物、8块；内外层均仍留整块。结果：

|属内训练＋属内测试|Class PCs|相对Class分位数|整体水平/参考组|
|---|---:|---:|---:|
|ASI/ASJ刺激后|−0.23350|−0.10144|−0.13951|
|ASK刺激后|−0.02159|−0.00145|+0.00660|
|ASK刺激期|−0.00804|−0.01714|−0.00021|

删任意一个测试菌株后，两种化学类别模型的三个目标仍全部为负。ASI/ASJ对应范围为PC −0.27818至−0.15877、分位数−0.12190至−0.05633。这是固定已拟合预测的影响检查，不是重新拟合后的独立验证。该检查足以降低对目前Class表示能解释同属神经差异的信任。

## 现有模型是否至少提示一个具体化学类别

只对07主线同一16只动物、4个实验块的五细胞高低组对比，分解已拟合Class模型的预测；没有追加拟合、特征筛选或寻找最佳细胞。将每个Class的两条PC合并贡献，避免PC符号和跨折轴交换产生虚假解释。

Class PC模型对ASI/ASJ/ASK/ADF/ASH的平均预测差为+0.00258/+0.01452/+0.02251/−0.08355/−0.07887 ΔF/F₀；五个均值方向与实测一致，但新增ASI几乎没有被重建。相对Class分位数对ASK约−0.000065，连方向也未保留。

Phenols注释类（3-Methoxytyramine、p-Cresol、p-Hydroxymandelic acid）在PC模型中对ASK和ASJ的贡献均值为+0.00648/+0.00491，4个块均为正；分别只有实测+0.108/+0.151的很小部分。Indoles类对ASJ贡献+0.00587，其中1/4块为负。贡献来自同一失败或弱预测模型，且各Class共变，不能据此把Phenols或某一分子认定为驱动因素。该审计保留为微弱的模型线索，不升级成命名的化学解释，不生成主图。

## 重要试错记录

1. 最初沿用stim/full窗口；神经侧提出ASI/ASJ刺激后组合后，中止尚未完成的首次试跑，加入post并完整执行，没有按化学结果选择新窗口。
2. 首轮内层仍沿用前轮4个λ及训练尺度标准化损失。自查发现与本轮04的比较目标不同，统一为5个λ及原单位MSE后完整重跑；本文及表均为统一后的最终数值，旧中间数字不用于结论。
3. 化学类别压缩失败后，有限追加一次“训练端同属中心”的反证，目标事先锁定为ASK stim/post、ASI/ASJ post；结果没有改善，停止该路线扩展。
4. 五细胞Class贡献仅解释已存在模型，未据几个正贡献增加模型或宣称机制。没有画化学类别机制图。
