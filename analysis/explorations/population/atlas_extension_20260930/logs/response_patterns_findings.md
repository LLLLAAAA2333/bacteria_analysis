# ASI/ASJ之外的群体响应分工：实际执行记录

## 可保留的判断

在既有ADF/ASH现象之外，较弱的ASI、ASJ和ASK也包含可重复的菌株差异。根据其他动物的ASI/ASJ刺激后均值给同一刺激目录排序，留出动物的ASI和ASJ差异仍出现；**未参与排序的ASK也随之升高，而ADF/ASH通常较低**。这一关联覆盖多个菌属和实验块，但不能命名为固定的两个相互对立的神经模块。属内反例直接否定了这个更强叙事。

本分析先检查13类神经元的宽阶段响应及78个细胞对，再选择ASI/ASJ的[10,30)秒均值。这一选择使用了全数据，随后检查是内部稳健性检查，不是独立验证。没有计算p值、FDR或宣称显著性。所有图中的响应均为上游处理后的ΔF/F₀；不换算放电、连接关系或行为效价。

## 直接证据与覆盖

ASI与ASJ共同覆盖40只动物、494个动物×菌株、106株。先在动物内对菌株响应去均值，再等权平均动物和同株不同实验块，post菌株均值Spearman相关为0.464；仅保留至少3株的菌属，在属内去均值后为0.519，覆盖88株。这只是共变描述，trial、神经元和菌株行均未冒充独立动物。

训练动物的ASI响应次序能预测另一只动物的ASJ次序：38个留整动物折，相关中位0.378，36/38为正；反向ASJ→ASI中位0.253，32/38为正。每株至少有两只其他动物参与训练，同一动物所有菌株和细胞整体留出。这个跨动物、跨细胞检查挑战了“仅因同一只动物的瞬时共同波动而相关”的解释；共同刺激序列及共同记录/处理偏差仍未被排除。

更直观的检验每折用训练动物的(ASI post + ASJ post)/2，固定选三株较高、三株较低，再读取测试动物的曲线。所有五类神经元及六个所选菌株完整覆盖的共同集合为32只动物、63个不同菌株、8个实验块。该五类集合在读到其余细胞差异后确定，不作预注册宣称。

## 真正可能推翻结论的检查

1. **跨动物的转移。** 上述cross-cell相关及严格留整动物选组均实际运行。它们检验同一目录不同动物的一致性，不是未知菌株或跨日期验证。
2. **首个与后续trial。** 固定原训练选组，首个保留trial的五细胞差仍分别为+0.091、+0.209、+0.110、−0.389、−0.181；方向一致动物数为23、27、24、25、24（均/32）。后续trial共同覆盖31只，分别+0.068、+0.102、+0.075、−0.142、−0.125，一致数28、27、22、23、24。ASI/ASJ首trial全菌株共变明显减弱，相关0.289，不能说每trial同样稳。
3. **少数菌株或实验块。** 删除高值A247后，ASI/ASJ菌株相关仍0.448；删除每次分数绝对值最高三株的结果另有完整表。逐个删除任一实验块，五细胞动物平均差的范围分别为[+0.0577,+0.0778]、[+0.1107,+0.1333]、[+0.0690,+0.1012]、[−0.2272,−0.1700]、[−0.1800,−0.0943]。这是删块影响检查，未重新寻找高/低株，不能称独立验证。
4. **共同信号或统一增益。** 在每动物每细胞去均值后，控制ADF/ASH的ASI/ASJ残差菌株相关为0.399；再加ASK/AWCON降为0.261，说明部分共享信息确实来自更广的响应状态。控制其他11类原单位均值或标准化中位数后为0.450、0.481。不同控制项需要不同缺失覆盖，表中记录确切N，不直接比较大小作机制推断。五细胞高组均值向量拟合为低组向量乘一个最优非负增益，相对残差范数中位0.660；原点归一化后ASI/ASJ/ASK仍28/29/26只增加，ADF/ASH只有18/20只降低。因此保留组成变化，降低固定对立关系的说法。
5. **刺激顺序。** 每动物、每细胞对平均保留segment作线性去趋势，ASI/ASJ全菌株相关0.450；五细胞对应差+0.066、+0.125、+0.081、−0.186、−0.150。这个诊断用到了该动物所有刺激，只用于敏感性，不声称是可部署预测或能排除非线性适应/携带效应。
6. **真正的属内反例。** 每属同目录至少3株时，训练动物选该属的一株最高、一株最低，再看留出动物。Bacteroides中ADF差−0.384（15/16负），而Escherichia中ADF差+0.205（3/3正），ASK也没有普遍增加。完整五细胞“对立程序”因此不成立；在混合目录中的重新分配只能作为条件性群体规律，不能替代每属内的机制。

另运行了基线扣除；存储曲线的刺激前均值最大绝对值仅1.8×10⁻¹⁶，已被上游处理归零，所以新扣除与原值相同。**这只是代数检查，不列为支持稳健性的额外证据。**

## 放弃或降级的路线

- ASK/AWA刺激期负相关在post及属内明显减弱，不能建立通用互抑组合。
- ADL/ASG等弱细胞虽然同动物内部有些相关，跨菌株关联较弱，当前不为每一类强造模块。
- AWB、ASER和AWCOFF的大部分极性是普遍的阶段反应，不直接等于菌株区别。在±0.02 ΔF/F₀描述性死区下，AWB有77/106株从负到正，ASER61/106；AWCOFF刺激期106/106为负，88/106刺激后仍为负。它们可作为atlas的响应背景，但这些比例本身不能提供菌株化学机制。0、0.02、0.05三个死区及first/later全部保存；死区不是经过噪声校准的事件阈值。
- 不保留“ASI/ASJ是专属连接模块”：ASK/ASJ的post中心化菌株相关0.475还略高，ASK/ASI为0.331；描述为更广群体状态更合适。
- 不把关联的负方向等同放电抑制，不把post变化解释成直接由撤除触发的放电机制。
