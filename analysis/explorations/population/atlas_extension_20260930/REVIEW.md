# 从 ADF/ASH 扩展到群体响应：本轮检阅

**神经侧已经可以向“有分工、也有冗余的响应组合”推进。AWA、ASK补充了ADF/ASH之外的信息；低幅度的ASI、ASJ也参与了一种跨动物可见的群体响应变化。化学侧能部分预测这项变化的方向，但还不能解释同属菌株差异，不能称为分子机制闭环。**

优先检阅以下三点：

1. **最值得先看的是实际群体响应，而非预测分数。** 在其他动物中用ASI/ASJ选择高、低响应菌株，再看留出动物：同一批32只动物的ASI、ASJ、ASK平均变化分别为+0.069、+0.126、+0.084 ΔF/F₀，ADF、ASH为−0.195、−0.137。ASK没有参与选组，仍有25/32只动物同方向，是新增的跨细胞支持。见[核心响应图](figures/response_patterns_asi_asj.png)。首轮/后续trial和跨动物跨细胞检查保留部分模式；但幅度归一化和属内检查削弱了固定“两个对立模块”的解释。因此保留“响应重新分配”的候选，放弃固定对立模块的强叙事。

2. **AWA、ASK是ADF/ASH之外最可靠的扩展，不能强行要求13类都独立贡献。** 匹配的39只动物中，四细胞组合的菌株辨认率为46.01%，ADF/ASH为33.99%；只保留负/近零/正三态，仍从22.11%升至34.59%。限制在同属候选，增益仍为6.20和12.37个百分点；去掉占多数的Bacteroides也保留。见[贡献审计附图](figures/atlas_roles_incremental.png)。四细胞组合是本数据上后验选出的发现，尚未独立验证。AWB、ASER、AWCOFF的广泛阶段响应与菌株辨认是不同角色；ADL、ASG等目前没有足够证据赋予菌株特异性作用。

3. **化学信息对应了群体变化的一部分方向，却没有解释其细节。** 在五细胞和六个选定菌株均有化学留出预测的16只动物中，162特征面板重建了五个平均变化的方向，但新增ASI/ASJ/ASK的预测差仅为实测差的约14%–24%。见[化学重建对照](figures/population_bridge.png)。ASI/ASJ平均post响应的留出菌株均值预测R²为0.136，删任一测试块仍为0.107–0.165；限制到同动物、同菌属后降为−0.096。直接用属内变化重新训练也未挽救，AWA同样未得到化学解释。这里的负分数说明这些模型未预测好，并不说明化学因素没有作用。

**研究决策：神经表型可围绕“ADF/ASH/AWA/ASK的互补信息”和“ASI/ASJ/ASK共同变化”继续组织；不要采用“全部13类不可替代”“固定兴奋/抑制模块”或“某个化合物已解释atlas”的表述。** 最有把握的是新增神经元提供动物间、部分属内辨别信息；最脆弱的是把群体共变归因到具体化学组。已有结果没有否定整个数据的价值，也没有把日期效应作为科学结论。
