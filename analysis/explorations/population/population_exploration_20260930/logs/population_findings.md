# 多神经元组合：执行记录与可保留判断

本任务使用上一轮核验后的动物响应表、动物曲线和项目分类表，实际执行了13类神经元的刺激期[0,10)、刺激后[10,30)及完整[0,40)秒探索。没有先压成菌株距离矩阵，也没有使用化学数据。下面的两个神经元及四个菌属是查看全13类响应后选择的探索性例子；不是预先规定的神经元模板。所有菌属名称均沿用项目 `genus_clean`。

## 最值得保留的现象

**相似的ADF正向钙响应可以伴随相反方向的ASH响应，不能用所有神经元共同放大或缩小来完整解释。** 这不是“ADF与ASH协同”的证据，而是两条可分离响应轴的具体例子。

- Escherichia：5株、3个物种，ADF刺激均值5/5株为正；ASH刺激均值5/5株为负，范围−0.111至−0.051 ΔF/F0，动物–菌株行25/26为负。ADF群体均值受A077较大响应影响，但删去任何一株都不会改变ASH平均的负方向。
- Lactobacillus：5株、3个物种，ADF和ASH刺激均值均5/5株为正；ASH范围0.055至0.571，动物–菌株行22/24为正。删去单株后ASH群体均值仍在0.164–0.293之间。
- Bacteroides：29株、16个物种，ADF和ASH刺激均值均29/29为正，说明“两个轴均正”也有较广的测量覆盖。
- Bifidobacterium：11株、6个物种，ADF整体较弱，ASH多数株为正但异质性大，适合作为组合空间中的位置说明；不能把全属统一归为某种固定响应程序。

上述动物–菌株行不是独立生物学重复，具体真实动物数与日期覆盖保存在 `population_selected_group_support.csv`，每只动物接受多个菌株。

## 最有区分力的反证检查

Escherichia与Lactobacillus有一个包含相同动物的直接比较：A065/A084/A215 对 A138/A206。对每只动物先在各菌属内部平均菌株，随后取两组差值，不把神经元、trial或菌株行当作额外动物。

主图B/C严格使用同时有ADF和ASH的**同一组3只动物**。刺激期 Escherichia−Lactobacillus 的ADF差为+0.1215、−0.0481、−0.1124，均值−0.0130；ASH差为−0.5560、−0.1445、−0.1787，均值−0.2930。均值较接近的ADF响应与ASH方向切换出现在相同动物中，不能简单归结为不同动物整体反应大小。这里没有进行ADF等效性检验，不能宣称两组ADF已证明相等。

这个ASH差在三只动物的trial中位数、first、later、trace-QC及线性顺序修正下均保持同一方向；顺序修正后的均值为−0.2902。全Escherichia/Lactobacillus五株的ASH均值符号，也在这六种响应汇总下全部保留。完整数值见 `population_joint_variant_contrasts.csv` 和 `population_variant_checks.csv`。

若只要求ASH测得而不要求同时测到ADF，则有5只共同动物，ASH差均值−0.3258，条件于这一实际比较的动物bootstrap百分位区间为[−0.4476, −0.1976]。这5只的结果只作为附表支持，主图没有将它与另一组3只ADF动物混成同一向量。

刺激后Escherichia ASH有较小的回升（株均值平均0.035），其完整40秒均值约0.003。将40秒全程压成单一均值会掩盖刺激期的符号差异。这里描述的是拟合基线后测得的钙信号下降/上升，不直接等同于放电抑制/兴奋。

最强仍存替代解释是固定或相近刺激顺序下的非线性适应和携带效应。first/later、trial中位数、线性顺序修正不能识别任意carryover，因此保留的判断是“在这些记录中跨动物可见的响应组合差异”，不是已证明菌属的内在因果机制。该局部同动物比较覆盖有限，推广到整个菌属需要保留边界；详细设计仅在附表记录。

## 全13维对共同增益假说的检查

原单位PCA的刺激期前三轴占70.3%、11.4%、7.5%的菌株均值变异。第一轴几乎由AWCON主导，绝对载荷约0.992，不能把第一主成分命名为所有神经元的“总体神经强度”。第二轴主要是ADF，第三轴混合AWA/ASEL/ASH。完整loadings和得分均已保存，正负号本身没有生物含义。

真正的反证采用同步划分动物：每个日期内将真实动物分为两半，同一动物的所有菌株、神经元和窗口始终一起划分；在一个半组拟合响应谱，在另一半组重建同一批菌株的13维响应，再交换方向。没有插补神经元；每次保留两半均完整测得13类的62–99个菌株–日期组合，中位88。所有模型使用相同的保留单元。

刺激期跨动物重建R²的300次划分中位数如下（基线为训练动物的共同均值谱）：

| 模型 | 中位R² | 划分5–95%范围 |
|---|---:|---:|
| 共同均值谱乘以每株增益 | 0.0844 | 0.0511–0.1294 |
| 最佳单一谱乘以每株系数：uncentered SVD学习共同谱 | 0.2995 | 0.2032–0.3878 |
| 均值谱加一个自由变化轴 | 0.5226 | 0.4157–0.5990 |
| 均值谱加三个轴 | 0.5844 | 0.3836–0.6844 |
| 均值谱加五个轴 | 0.6364 | 0.4415–0.7342 |
| 完整13维半组均值 | 0.6245 | 0.4354–0.7191 |

这支持记录中的可重复信息包含响应组成，而不只是一个共同谱的乘法增益。五轴略胜完整13维符合去除噪声的作用，**不据此宣称恰有五个生物学程序**。模型阶数1–13全部记录，没有在测试半组选择最优阶数后包装成验证。刺激后/全时段也保留多轴优势，完整表见 `population_reconstruction_summary.csv`。

上述范围是动物划分敏感性，不是置信区间。它评估相同菌株目录在另一组动物的重建，不是新菌株、新日期或独立实验验证。日期去均值版本仅作为内部敏感性列保留；主图没有以日期作为主要科学故事。

## 实际考察但未保留为重点的路线

1. **一个全局增益就足够。** 共同均值谱和更宽松的最佳单一谱均不能达到多轴重建，具体ADF/ASH同动物例子也与简单统一增益不符。
2. **PCA第一轴就是总体响应强度。** 载荷几乎集中于AWCON，这个命名会误导，放弃。
3. **PCA第三轴或Bifidobacterium平均AWA可直接称稳定神经模块/菌属程序。** 第三轴方差约40%来自三个高分菌株，Bifidobacterium的AWA响应也只集中于少数株。没有把它硬凑成主要发现；保留全部得分、载荷与属分布供后续检阅。
4. **先标准化再将小振幅神经元解释为等强轴。** 运行了unit-SD及动物残差SD缩放的诊断PCA，但主判断回到原ΔF/F0和动物曲线，避免尺度标准化放大弱信号。
5. **将ADF/ASH低相关称为协同。** 全菌株刺激均值相关仅约0.16，说明可分离的强弱/方向组合；没有做超出数据的协同或因果网络解释。
