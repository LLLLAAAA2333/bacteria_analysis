# 化学候选组：定义、覆盖与限制

这部分只读取上一轮的化学报告、特征注释、QC、分类表和参考组，没有读取神经响应。观测单位为106个菌株各一份化学参考剖面。162项满足配对菌株全检出且QCRSD≤0.30；这不等于实际刺激液浓度或确证分子身份。

运行命令：

```sh
.pixi/envs/default/bin/python reports/population_exploration_20260930/code/04_chemical_groups.py
```

脚本已成功运行，终端日志在 `chemical_groups_run.log`，参数、版本、输入SHA及状态在 `chemical_groups_summary.json`。所有输出使用 `chemical_groups_` 前缀，旧输入在运行前后校验一致。

候选并非预先注册：先检查报告结构，再固定化学一致性规则，不使用神经结果。扫描SuperClass/Class/SubClass/DirectParent中≥3项的组；完全相同成员集合去重并保存别名，共33组。进入候选需3–12成员、成对相关中位数≥0.20、正相关比例≥0.85、每成员与其余成员分数的相关≥0.10。全部未入选组仍在 `chemical_groups_audit.csv` 与 `chemical_groups_all_scores.csv`，避免只保存看起来一致的类。

宽泛的氨基酸/肽57项、脂肪酸21项和吲哚7项，成对相关中位数仅为0.151、0.060、−0.131，不适合当作单一同向状态。按注释求平均不能解决类内相反变化；这些值也不表示这些化学类没有神经相关信息。

## 整体水平、分类背景和冗余

`chemical_groups_audit.csv` 保存总水平相关、菌属/参考组描述R²、调整后剩余变异、成员删一敏感性和类内一致性。整体水平取162项标准化log的中位数；调整时移除当前组成员，避免直接的部分与整体重叠。它不是总分子浓度、培养密度或已知批次变量。

- 季铵盐与留组外整体水平相关0.860，蝶啶0.758，胺类0.702，单看这些分数容易重复描述共同化学变化。
- β羟基酸的菌属R²为0.748、参考组R²为0.631；属内成员相关降至0.060，联合菌属、参考组及整体水平后的成员相关中位数约0.035。它更依赖本面板的背景分组，不能据此确认背景造成了这些化学差异。
- α羟基酸与整体水平相关0.188、参考组R²为0.012，保留相对不同的变化方向，但组内一致性偏弱，成员删一分数相关最低0.818。
- 各候选仍有属内变化；相对原分数的属内剩余SD为0.50–0.81。分类水平多、部分菌属只有一株，分类R²会受覆盖影响，因此同时保存调整R²、分层覆盖和具体范围于 `chemical_groups_within_genus.csv`。
- 亚油酸相关的3项沿用报告拼写“Lineolic”；它们的Mass均为279.2/279.2，RT为11.38–11.48，不能当作三个独立分子证据。是否为可区分异构体或分析冗余，现有注释不能确定。

## 数据共变模块仅作另一种探索性描述

在162项的正Spearman距离上做complete linkage，截断保证原面板模块内每对ρ≥0.65。得到15个≥3成员模块，完整分数和成员均保存，但没有将15个模块全部推广为神经候选。仅将两个≥8项的大模块放在 `chemical_groups_exploratory_module_scores.csv`。随机种子2026093004，200次按菌株有放回重采样并重新聚类，检验的是该面板下的成员边界敏感性，不是化学实验重复性或独立验证。

- **module_02，11项脂肪酸相关注释。** 成对ρ中位数0.841，属内0.749；原模块成员两两在bootstrap中仍同群的概率中位数0.865，最低0.600。联合调整菌属、参考组和整体水平后还保留原分数71.6%的SD。成员为Arachidic Acid、Conjugated linoleic acids (CLA)、Elaidic Acid、Erucic Acid、Lignoceric Acid、Linoelaidic acid、Linoleic acid、Oleic acid、Palmitic acid、Petroselinic acid、Stearic acid。
- **module_01，14项含氨基酸及其他注释的混合模块。** 成员同群概率中位数0.465、最低0.165，固定成员边界敏感。不能据此宣称它是一条确定的代谢通路；成员边界不稳也不证明共同变化不存在。
- module_02与ann_16分数ρ=0.95，不能算成两条独立化学解释。module_02仅7种Mass×column组合；为检查相近注释重复加权，将每种组合内先取中位数，再对组合取中位数，所得分数与原分数ρ=0.979。这个保守敏感性不等于完成了分子去重。结果在 `chemical_groups_transition_balanced_scores.csv`。

## 后续使用与验证

任何预测CV都应在训练株上估计特征均值和SD，再对测试株应用。当前组一致性筛选及模块是全106株化学数据探索，使用完整面板分数时应标明transductive；若要评估整个选择算法，应在训练折重做筛选/聚类。注释组可作为后续冻结的候选定义，但当前神经关联仍是探索性的。

本次独立用源报告值重构7个候选分数，最大误差7.22×10⁻¹⁵；检查了106行、25个候选成员、48个总组、QC门槛、模块成对相关下限及脚本语法，均通过。没有检验神经解释、分子机制、培养批次匹配或新的化学生物学重复。
