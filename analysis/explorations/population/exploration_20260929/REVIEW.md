# 检阅后的证据重评

更新：2026-09-30。本轮已经完成计算、候选筛选和有效性核查，但**尚未回答“哪些菌株神经响应差异值得解释，以及化学特征能怎样解释它们”这一研究问题。** 上一版将局部对照、重复性检查和候选相关提升为三个优先发现，交付定位不当。撤回这一定位，保留计算记录。

已有记录只支持有限观察：部分菌株的ADF响应幅度不同；一些菌株在所测动物中引起较强AWCON响应；个别化学参考特征与这些指标共变。观察到差异、确认它不由少数异常值造成，仍不足以说明其科学含义。上一轮缺少的是一条有区分力的解释：这些菌株究竟共享什么响应模式，化学信息解释了模式的哪一部分，以及它优于哪些竞争解释。

## 现有图的正确用途

|图|本次定位|尚不能承担的结论|
|---|---|---|
|01两张图|数据概览和局部曲线查看|有解释力的神经表型|
|02 ADF跨日|局部对照和重复性核查|ADF总体规律或数据整体可靠性的判决|
|03 AWCON|强响应候选及其动物覆盖、幅度变动检查|解释了这些菌株为何产生这种响应|
|04 chemical explanations|单特征筛选、调整与预测诊断|已经得到化学解释，或已经证明日期批次效应|
|05 Asparagine–ADF|事后候选关联与适用范围检查|天冬酰胺或物种已经解释ADF差异|

这些图保留在分析记录中，当前不推荐其中任何一张作为研究主图。图的面板数量和计算通过检查，都不能替代科学证据。

日期是采样与依赖结构的一部分，需要在比较中处理，不能取代菌株神经响应这个研究对象。图04及图05 B/C去掉动物整体偏移后比较菌株相对值，没有直接检验日期的因果作用；按日期着色也不能证明批次效应。

**本轮没有得到“整个数据重复性差、不能继续研究”的证据。** 某个局部对照跨日变化只限制该对照的推广；某个候选关联受样本范围或物种构成影响，只限制该候选的解释。化学解释尚未完成，应归结于本轮分析没有解决问题，不能归结为数据已被判定不可用。
