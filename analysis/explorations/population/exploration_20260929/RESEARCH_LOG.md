# 本轮研究记录

日期：2026-09-29。范围由本轮用户授权：实际运行一轮神经现象出发的探索，检验化学解释，交付可复核结果。只写本目录，不修改原始数据、既有 Notebook 或其他工作。归档交接中的旧候选、数值和解释不作为可信前提。

## 候选问题与选择

1. **菌株是否改变某些神经元的响应方向或幅度？** 查看全部13类、106菌株和112菌株×日期的原单位响应，并检验同日期不同动物是否给出相似的相对差异。这是主入口。
2. **这些差异是否只是全体神经元一起增强？** 选择AWCON的强响应菌株后，在相同动物内查看其余12类的对比。区分特定响应组合和简单共同增益。
3. **刺激中与撤除后钙信号能否给出稳定菌株身份？** 查看粗时间窗和六株跨日记录；没有继续拟合潜伏期、峰时或衰减常数。
4. **化学参考剖面对应了哪种已见到的差异？** 仅对神经侧选出的ADF和AWCON刺激期均值探索关联，不进行神经/化学距离矩阵整体相关，不继承旧己酸—ASH或四细胞轴。

选择ADF和AWCON两条神经主线：ADF既有动物间一致性，又有相同菌株对照在两日期可比较；AWCON具有大的、选择性强的正响应，适合用同动物和化学反例区分解释。AWA和ASH也显示动物间一致性，但本轮未深入，不能把未选择写成无效。AWB撤除后响应虽同日一致，却在跨日记录中明显改变，因此降低时程路线优先级。选择依据包括效应、设计支持和解释区分力，没有用最小p值排序。

## 实际执行与重要选择

- `01_prepare.py` 从parquet重算完整曲线。先平均trial内可用双侧，再平均动物内trial，再平均日期内动物；跨日描述等权日期。观察单位为动物×菌株×神经元的曲线，独立动物身份为`date + worm_key`。时间零改为刺激起始；刺激[0,10)秒，post[10,30)秒，full[0,40)秒，另存late[30,40)秒。八个5秒窗仅留作可追溯表，本轮不筛选最有利时间窗。
- `02_neural_overview.py`：500次动物划半。每次每日期所有菌株和神经元共用同一动物分组；分别在相同菌株集合上去日期均值。分割分布不是独立验证或置信区间。另做删除三个最大日期内偏差菌株、每半至少两动物、六株两日期原值比较；1000次动物重采样跨菌株同步。
- `03_chemical_prepare.py`：按AID核对106株；名称仅做NFKC字符标准化。核实单位来自源文件的比较页，QC RSD从39次QC重算。数值反推7组参照分母并重建旧矩阵；不赋予未记录的参照生物学身份。
- 化学处理保留源表缺失，不填0作为主分析。先登记QC RSD≤0.30且非缺失≥90%的248项；看到实际缺失范围后，主筛选固定为其中全106株无缺失的162项，以减少插补假设。248项只用于训练集菌株中位数插补的敏感性。筛选规则不使用神经响应。
- `04_phenotype_checks.py`：对ADF六个跨日菌株和AWCON强响应组直接画动物曲线。七株AWCON组来自同一数据的幅度间隙（均值>1.8，下一株1.239），属于事后描述分组。ADF的A024−mean(A013,A014)因两天可在同动物内比较而保留；它也由本轮数据选择，不能称预先设计检验。
- 反证包括trial中位数、首个保留trial与后续trial、去掉原通道出现ΔF/F₀<−1的整条类神经元trial、由动物×菌株内变化估计的线性segment趋势校正。顺序校正无法重建随机化，不能消除未观测的携带效应。
- `05_chemical_tests.py`：两个目标各扫描162项，记录全部结果，不给确认性p值/FDR。加权联合投影去动物截距，权重让每个菌株×日期贡献总和为1；再考察参照组、化学整体水平和菌属。保留所有共变特征记录，不把排名第一当作唯一分子。
- 日期留一时每折重新选化学特征、估斜率；所有六个跨日菌株都排除，余100株不在训练/测试间重复。测试目标是同批动物内的菌株相对响应，使用同样的动物中心化定义；不预测绝对幅度，不用测试结果校准斜率。日期留一仍不是独立验证，神经目标和窗口已看过全数据。
- 第二阶段：已计算的联合调整筛选中，Asparagine是ADF最大的绝对残差关联，并与A024/A025和A013/A014的具体差异相符。因此只追加这一条有界检查，不再寻找其他分子。`06_asparagine_check.py`检验菌属内外、物种、六个化学高值菌株、逐日/逐株删除及神经指标敏感性。此路线与新增的筛选规则敏感性均由全数据触发，明确属于发现阶段。

## 被否定、降低信任或停止的路线

- 未复用旧整体距离关联、旧四细胞轴、旧近邻实例和旧分子显著性；本轮没有必要重做它们。
- 没有保留“13类中所有响应都可跨日稳定重现”的说法：A044的ADF是具体反例，六株重复也全部属于Bacteroides，覆盖有限。
- 没有把AWCON强响应称为跨日重复：七株各只有一个日期。相同动物后续trial普遍减弱，精确幅度不能视为固定菌株常数。
- 没有保留“低Arginine足以解释AWCON强响应”：同日A247/A249构成反例，菌属调整后关联反向，删七强株后关联接近零。
- 第一阶段ADF最大关联1-Methylhistidine没有形成可迁移解释：每折重选后的相对预测误差只小幅改善，且仅4/9日期改善；多项化学特征高度共变。第二阶段Asparagine另作检查，不能偷偷替换第一阶段的不利结果。
- 不把报告中的ng/mL直接当线虫实际暴露浓度。缺少培养批次、刺激液稀释、pH/渗透压、标准品/校准和注释等级。本轮停止在菌株参考化学剖面关联，未拟合分子因果模型。
