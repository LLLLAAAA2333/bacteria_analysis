# 神经贡献分析：不同化学近邻是否总由同一两个细胞区分？

本路线预先同时纳入13类细胞，不固定ADF/ASH，不再训练菌株分类器。分析对象为01脚本已定义的147个同采集block、同菌属、同化学参照的菌株对。主要解释范围是其中存在至少3个可选菌株时选出的化学近邻：28对，其中26对支持每类细胞至少3个配对动物的完整13类面板；其余2对的不足不能补零。本子分析的完整面板26对涉及36株、6个block。重复单位仍是动物；共享动物/菌株/采集block的pair相互依赖，以下pair计数和范围不构成独立实验样本量。

## 保留的判断

在细胞平衡的共同坐标下，不同近邻的神经差异贡献位置不同，而非总由ADF/ASH承担。26对的最大正贡献来源覆盖8类：AWB 5对、ADF 5对、ASH 4对、AWCOFF 4对、ASG 3对、AWA 2对、ASJ 2对、ASK 1对。最大细胞占正贡献之和的中位数为42.0%（18.0–72.1%），正贡献有效细胞数中位数为3.42（1.86–7.21）。这描述的是本目录中的贡献分布；不证明8种通路、细胞机制，亦不证明其余5类必然有用。

全数据中25/26对的总体跨动物差异统计量为正；从每对删除其最大贡献细胞后21/26仍为正。这只是对“所有群体差异都来自一个细胞”的敏感性检查，不能把正数当作显著、验证成功或因果差异。逐对的负值和近零值全部保留，不将其命名为已证实的神经相近。

## 能削弱判断的检查

**坐标依赖很实质。** 使用原始dF/F0平方而不平衡细胞尺度时，最大细胞只覆盖5类：ASH 10对、ADF 9对、AWB 3对、AWCON 2对、AWA 2对。只有14/26对的最大细胞与平衡坐标相同。因此图必须说明“相对于各细胞自身响应变异的差异”，不能把8类最大贡献解释为物理幅度等量贡献或宣称所有13类都同样重要。原始单位更偏向ADF/ASH，本分析并未否定这一事实。

**先选择再看未参与选择的响应。** 对每个pair和每个留出动物，用其他动物的首次presentation计算各细胞跨动物差异统计量，选最大者；在留出动物的后续presentation上计算其配对差向量与训练首次差均值的5-bin内积。这个测试动物的所有trial均排除在选择和尺度拟合之外；尺度也仅用其他动物首次presentation按01的同一定义重估。反向以其他动物后续presentation选择、留出动物首次presentation检验。训练至少2个配对动物；测试存在缺测时，仅用训练及测试都可计算的细胞，逐fold实际为6–13类，并非所有动物同时完整13类。

首次→后续方向，26对中20对所选细胞的平均留出内积为正，删去该fold所选细胞后25对剩余平均内积为正。反向分别25和20对。正数数量不能作为验证率：pair依赖、数据少、共同协议和顺序仍在；第一次/后续次也不是独立生物学重复。两种方向不完全相同，意味着“由某个固定细胞稳定主导”的表述过强。这里没有计算p值、显著性阈值或近/远硬标签。

## 数量定义与复现

对每个神经元c，01提供U_c，等于不同动物的5-bin配对差内积的均值；正负均保留。总体为13类的U_c / scale_c²平均值。图中带符号的单细胞贡献为U_c / scale_c² / 13。仅在贡献集中度描述中取p_c = max(U_c / scale_c², 0) / Σ max(U / scale², 0)，最大份额为max(p_c)，有效正贡献数为1 / Σ p_c²。此正部归一化不改变总体统计量，但会放大小样本噪声产生的正项；有效数不是生理模块数量。最大细胞也是同数据选择的描述结果，不是独立验证。
